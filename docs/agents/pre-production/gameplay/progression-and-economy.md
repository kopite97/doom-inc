# 성장·경제·밸런스 준비 지침

반복 플레이가 새로운 선택으로 이어지고 자원은 어디서 부족해지는가?

## 시작할 자료

[성장](../../../game-design/experience/growth.md)·[자원](../../../game-design/systems/resources.md)·[연구](../../../game-design/systems/research.md)에 채택 방향이 있다.

## 준비 방법

1. 초반·중반·후반에 접근 가능한 행동과 해금 조건을 적고, 해당 단계 진입에 필요한 연구·시설·생명체를 연결한다.
2. 대표 자원 하나를 골라 유입·저장·소비·고갈 후 회복 경로를 추적한다. 공급 확보가 어떤 다음 선택을 여는지 적는다.
3. 규칙으로 정할 조건과 플레이 테스트에서 측정할 획득량·소요 시간·난이도 값을 구분한다.

## 산출물과 확인 기준

**성장 단계도와 대표 자원의 수급표**를 준비한다. 해금 전후의 판단 차이와 자원 부족에서 회복하는 경로를 설명하고, 진행 속도를 조정할 관찰 지점을 찾을 수 있다.

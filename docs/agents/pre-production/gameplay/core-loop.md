# 코어 게임플레이 준비 지침

플레이어가 어떤 판단을 반복하며 무엇을 새로 얻게 되는가?

## 시작할 자료

[초반 흐름](../../../game-design/experience/early-game.md)과 [방향](../../../game-design/direction/overview.md)에 행동과 목표가 나뉘어 있다.

## 준비 방법

1. 대표 장면의 시작 상태, 눈에 보이는 단서, 플레이어 입력, 생명체의 자율 반응을 순서대로 적는다.
2. 선택 이후 무엇을 보고 성공이나 실패를 알아채는지, 보상이나 손실이 다음 선택에 어떻게 영향을 주는지 추적한다.
3. 한 번의 반복을 정상 상황과 자원이 부족한 상황에 각각 적용하고, 두 경우 모두 다음 행동으로 이어지는지 읽어 본다.

## 산출물과 확인 기준

**대표 플레이 장면과 반복 흐름도**를 준비한다. 관찰만 하는 구간과 직접 개입하는 구간을 구별할 수 있고, 반복할 이유와 막혔을 때의 선택을 설명할 수 있다.

# 게임 시스템 준비 지침

하나의 플레이 결과를 만드는 데 어떤 시스템 규칙이 연결되는가?

## 시작할 자료

[기획 MAP](../../../game-design/README.md)에 배양·운반·연구·방어 등 주제별 원본이 있다.

## 준비 방법

1. 대표 상황을 하나 고른다. 예를 들어 배양이 지연되는 장면이라면 원료 재고, 운반, 시설 가동의 담당 원본을 찾는다.
2. 각 시스템이 시작되는 조건·상태 변화·다음 시스템에 넘기는 결과를 순서대로 적는다. 정상·부족·중단 때 플레이어가 보는 차이를 확인한다.
3. 두 문서가 같은 상황을 다르게 설명하거나 결과를 정하지 않은 곳은 담당 원본과 함께 질문으로 남긴다.

## 산출물과 확인 기준

**시스템 간 규칙 연결표와 미정 질문**을 준비한다. 대표 상황을 처음부터 끝까지 따라가며 각 결과의 근거 또는 미정 위치를 찾을 수 있다.

# 사운드 준비 지침

어떤 소리가 분위기를 만들고 어떤 소리가 즉시 알아야 할 정보를 주는가?

## 시작할 자료

[사운드 디렉션 기획](../../../game-design/experience/sound-direction.md)에서 확정한 분위기와 남은 논의를 확인한다. [연출 도구](../../presentation-effects.md)와 [음원 배치 지침](../../project-structure.md)은 제작·적용 때 참고한다.

## 준비 방법

1. 평시·작업 완료·위험 예고처럼 대표 상황을 적고 음악·환경음·효과음의 역할과 재생·종료 조건을 구분한다.
2. 여러 시설의 완료음과 경보가 겹치는 상황을 가정해 우선순위, 반복 간격, 볼륨 조절과 소리를 끈 상태에서의 단서를 정리한다.
3. 대표 음원별 직접 제작·구매 후보와 필요한 이용 조건을 표시한다.

## 산출물과 확인 기준

**상황별 사운드 표와 대표 음원 조달 목록**을 준비한다. 조용한 상황·소리가 겹치는 상황·음소거 각각에서 플레이어가 받을 신호를 설명할 수 있다.

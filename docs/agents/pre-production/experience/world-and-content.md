# 세계관·서사·콘텐츠 준비 지침

세계관을 어떤 인물·생명체·시설·사건으로 플레이 중에 전달할까?

## 시작할 자료

[마스코트와 조수](../../../game-design/experience/characters.md)·[외부 세계](../../../game-design/systems/external-world.md)에 등장 주체와 관계가 있다.

## 준비 방법

1. 연구소, 주인공과 조수, 외부 세력이 서로 어떤 관계인지 원본에서 추려 세계관 요약을 만든다.
2. 콘텐츠 종류별로 플레이에서 맡는 역할과 만나는 시점을 적는다. 대표 사례 하나에 이름·행동·등장 조건·필요한 그림과 문구를 채워 본다.
3. 같은 양식으로 추가 제작할 때 필요한 작업 단위와 예상 수량을 적고, 세계관 설정과 콘텐츠 후보의 확정 상태를 표시한다.

## 산출물과 확인 기준

**세계관 요약, 유형별 콘텐츠 목록, 대표 항목 작성 예시**를 준비한다. 예시를 보고 다음 항목의 기획·텍스트·아트에 필요한 작업을 추정하고, 플레이 중 드러날 설정을 확인할 수 있다.

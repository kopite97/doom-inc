# UX 준비 지침

처음 접하는 플레이어가 문제를 알아차리고 해결 결과를 확인할 수 있는가?

## 시작할 자료

[화면과 상호작용](../../../game-design/experience/interface.md)에 행동·대기 이유 관찰과 방침 변경 흐름이 있다.

## 준비 방법

1. ‘시설이 대기하는 원인을 찾아 조치한다’처럼 사용자 과제를 고르고, 시작 화면과 성공 상태를 먼저 적는다.
2. 발견 → 원인 확인 → 가능한 조치 → 결과 확인을 따라간다. 처음 보는 용어, 과도한 입력, 잘못 눌렀을 때 돌아갈 경로를 표시한다.
3. 도움말 없이 시도할 플레이 테스트 과제를 쓰고, 설명이 필요했던 지점과 접근성·조작 편의 문제를 어떻게 관찰할지 정한다.

## 산출물과 확인 기준

**사용자 과제별 흐름도와 관찰 질문**을 준비한다. 과제를 시작하는 단서, 성공 피드백, 실수 후 돌아오는 경로가 각 단계에 나타난다.

# UI 준비 지침

대표 화면에서 먼저 읽어야 하는 정보를 어떻게 배치할까?

## 시작할 자료

[화면과 상호작용](../../../game-design/experience/interface.md)에 PC 화면 원칙과 레이아웃 제안이 있다.

## 준비 방법

1. 화면별 목적과 표시할 정보를 모으고, 항상 볼 항목과 선택 뒤에 볼 상세 항목을 나눈다.
2. 연구소 HUD와 패널을 흑백으로 배치한다. 평상시·선택 중·부족이나 경고 상태에서 표시가 어떻게 바뀌는지 그린다.
3. 작은 화면 폭과 긴 번역 문구를 대입해 잘림·겹침을 점검한 뒤 글꼴·아이콘·색상·버튼 상태를 지정한다.

## 산출물과 확인 기준

**화면 목록, 상태별 와이어프레임, 대표 화면 시안**을 준비한다. 시안에서 주요 행동 버튼과 현재 대기 이유를 찾을 수 있고, 경고를 색 외의 단서로도 식별할 수 있다.

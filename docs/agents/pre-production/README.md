# 게임 개발 사전준비 지침 MAP

준비하려는 분야를 골라 해당 지침을 읽는다. 각 지침에는 시작할 자료, 준비 방법, 산출물과 확인 기준이 있다. 준비 결과와 남은 질문은 [분야별 준비 현황](../../todo/pre-production.md)에 연결한다. 기획 결정의 상태와 원본 위치는 [기획 지침](../game-design.md)을 따른다.

## 게임의 방향성

- [게임 콘셉트](direction/concept.md) — 누구에게 어떤 플레이 경험을 약속하는가?
- [게임 목표·시장](direction/goals-and-market.md) — 어떤 이용 상황과 시장을 목표로 삼으며 성공을 어떻게 판단할까?
- [프로젝트 범위](direction/scope.md) — 가용 시간과 비용으로 어느 범위까지 만들 수 있을까?

- [게임 시스템](gameplay/systems.md) — 하나의 플레이 결과를 만드는 데 어떤 시스템 규칙이 연결되는가?
- [레벨·월드](gameplay/level-and-world.md) — 공간 배치가 플레이어의 운영 선택을 어떻게 바꾸는가?

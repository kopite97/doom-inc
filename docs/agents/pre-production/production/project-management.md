# 프로젝트 관리 준비 지침

제작 여건 안에서 어떤 순서로 결과물을 확인할 수 있는가?

## 시작할 자료

[로드맵](../../../game-design/development/roadmap.md)에 초기 단계와 경험 확인 기준이 있다.

## 준비 방법

1. 로드맵의 단계별 목표를 확인 가능한 산출물로 적고, 선행 작업과 직접 제작·구매·외주할 부분을 표시한다.
2. 가용 시간·예산과 대표 항목의 제작 시간을 이용해 일정을 추정한다. 추정의 근거, 여유가 필요한 작업, 가장 큰 위험과 대안을 함께 적는다.
3. 프로토타입과 대표 구간 제작 후 예상과 실제 소요를 비교해 남은 일정과 우선순위를 다시 보는 시점을 정한다.

## 산출물과 확인 기준

**마일스톤 표와 일정·비용 추정 근거**를 준비한다. 각 단계에서 무엇을 보고 완료를 판단할지, 지연 시 무엇을 먼저 조정할지 설명할 수 있다.

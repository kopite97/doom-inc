# 출시·사업·운영 준비 지침

어느 경로로 플레이어에게 전달하고 출시 후 어떤 지원을 제공할까?

## 시작할 자료

[게임 방향](../../../game-design/direction/overview.md)에서 정한 첫 출시 목표는 Windows용 Steam 출시다. 본편을 한 번 구매하면 배양부터 행성 전체 침공 엔딩까지 추가 결제 없이 즐길 수 있다. DLC와 macOS·Linux 지원은 추후 검토한다.

## 준비 방법

출시 전에는 유튜브에 개발 과정을 공개한다. Steam 상점 페이지가 열리면 개발 영상을 보고 관심을 가진 사람이 위시리스트에 추가할 수 있도록 안내한다.

1. 플랫폼과 상용화 목표가 미정이면 후보별 배포·가격·수익 모델과 선택 이유를 적는다. 목표 채널을 정하면 공식 등록·심사 요건과 확인일을 기록한다.
2. 스토어 문구·이미지·영상·홍보 일정, 콘텐츠 등급·개인정보·에셋 권리 확인 항목을 준비 시점과 연결한다.
3. 출시 뒤 받을 문의, 오류 보고, 업데이트와 공지 경로를 정한다. 분석할 지표가 있다면 수집 목적과 실제 운영에 사용할 결정을 적는다.

## 산출물과 확인 기준

**출시 준비 일정과 출시 후 지원 계획 초안**을 준비한다. 채널 선택 후 준비할 자료·확인할 요건·예상 일정을 찾을 수 있고, 출시 직후 문제를 접수하고 안내할 경로가 있다.

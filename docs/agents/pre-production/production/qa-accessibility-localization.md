# QA·접근성·현지화 준비 지침

어떤 사용자와 환경에서 게임의 동작·정보 전달·복구를 확인할까?

## 시작할 자료

[검증](../../verification.md)·[번역](../../localization.md) 절차가 있다.

## 준비 방법

1. 대표 사용자 과제를 골라 기능·호환성·성능·오류 복구 시나리오별 조건과 기대 결과를 적는다. 첫 사용자에게 제공할 안내 범위도 표시한다.
2. 입력 재설정·글자 크기·자막·색 외의 단서를 점검할 장면을 고른다. 음소거와 작은 화면 등 실제로 확인할 조건을 적는다.
3. 지원 언어 후보를 확인한 뒤 긴 번역, 누락된 글리프, 숫자·변수 표시가 깨질 수 있는 화면을 선정한다. 결과와 재현 조건을 기록할 위치를 정한다.

## 산출물과 확인 기준

**사용 환경·언어별 테스트 표와 플레이 관찰 과제**를 준비한다. 각 항목에 재현 조건과 관찰 가능한 통과 기준이 있고 미검증 환경을 식별할 수 있다.

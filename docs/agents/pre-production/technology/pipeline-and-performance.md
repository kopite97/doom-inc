# 개발 파이프라인·성능 준비 지침

같은 자료를 반복해서 제작·검증하고 같은 조건에서 성능을 비교할 수 있는가?

## 시작할 자료

[저장소](../../repository.md)·[프로젝트 구조](../../project-structure.md)·[하네스](../../harness.md) 지침이 있다.

## 준비 방법

1. 정의 데이터나 에셋 한 건을 골라 편집 → 임포트 → 검증 → 버전 관리 → 배포용 산출물까지 필요한 도구와 수동 작업을 적는다.
2. 반복 비용이 큰 작업과 자동화 후보를 표시한다. 실패했을 때 원본·설정·출력을 어디서 확인할지 남긴다.
3. 최소 사양 후보, 해상도, 맵 크기와 개체 수 등 대표 부하를 정의한다. FPS·메모리·로딩 시간의 목표 후보와 측정 조건을 짝짓는다.

## 산출물과 확인 기준

**제작 절차도와 성능 측정 조건표**를 준비한다. 다른 작업자가 같은 입력과 환경으로 제작 절차를 따라가고 측정 결과를 비교할 수 있다.

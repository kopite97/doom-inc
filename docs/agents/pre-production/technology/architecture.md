# 기술 아키텍처 준비 지침

어느 기술 선택이 여러 시스템에 영향을 주며 무엇을 먼저 검토해야 하는가?

## 시작할 자료

[기술 결정 이력](../../../decisions/README.md)·[구현과 재사용 지침](../../implementation.md)이 있다.

## 준비 방법

1. 기획과 범위를 정리한 뒤 대표 플레이에 필요한 기능을 기존 씬·프리팹·어셈블리·엔진 버전·패키지와 대조한다.
2. 상태를 누가 소유하고 어떤 순서로 바꾸는지 정리한다. 시스템 통신, UI 상태, 에셋 로딩과 외부 서비스의 의존성을 표시한다.
3. 변경 비용이 큰 선택은 기존 방식의 재사용 근거·대안·제약과 대표 실패 상황을 기록한다. 확인이 필요한 가정에는 검증 방법을 붙인다.

## 산출물과 확인 기준

**주요 경계도와 재사용·기술 결정 후보 목록**을 준비한다. 대표 기능 변경의 영향 범위, 재사용 근거, 실제 검증할 위험을 추적할 수 있다.

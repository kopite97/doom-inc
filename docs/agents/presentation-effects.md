# 외부 연출 에셋 사용 기준

현재 상태값을 표시하거나 Unity 기본 API 한 번으로 끝나고 코드에서 재생 시간·순서·중단을 관리할 필요가 없는 연출은 외부 에셋 없이 구현한다. 그 밖의 연출은 아래 기준을 따른다.

| 에셋 | 사용 기준 |
| --- | --- |
| DOTween Pro | UI나 오브젝트의 위치·크기·투명도를 목표 상태로 전환할 때 |
| Feel | 게임 사건에 반응해 효과음·진동·화면 점멸·흔들림을 재생할 때 |
| Text Animator | 글자나 단어 단위로 등장·퇴장·움직임을 연출할 때 |

정적인 문구는 기존 TMP 라벨로 표시한다. [문구·번역 지침](localization.md)

같은 대상의 같은 속성은 한 번에 한 곳에서만 제어한다. 화면을 닫거나 재사용할 때는 이전 연출을 정리한다.

# PLAN-NNN UI 전용 아트 제작·적용

아이콘·버튼·패널·HUD 등 UI 표시용 아트에 사용한다. 프레임 애니메이션이 필요하면 [애니메이션 양식](_template-art-animation.md)의 동작별 움직임 설명·재생 연결 표를 추가한다.
[아트 공통 작성 기준](AGETNS.md#art-template-records)·[타입별 완료 판정](AGETNS.md#타입과-완료-판정)·[전체 준비 후 테스트](../agents/verification.md#art-plan-test-readiness)를 따른다.
빌드·고부하 검증 포함 여부는 [PLAN 검증 범위 지침](AGETNS.md#작성과-기록)에 따라 요청 근거와 실행 범위를 기록한다. 빈 칸은 실제 사실로 채우고 해당하지 않는 항목은 이유와 함께 정리한다.

## 목표와 범위

- 작업 완료 후 알아볼 수 있어야 하는 외형·역할·상태:
- 포함할 에셋·사용 화면과 신규/교체 구분:
- 재사용할 에셋·기존 요청 ID:
- 제외할 에셋·기능·후속 범위:
- 필요한 최소 연결 코드·변경하지 않을 게임 규칙/저장 계약:
- 제작 담당·요청/위임 근거·현재 실행 범위:
- 사용자가 별도로 보류한 단계·재개 조건: 없으면 없음

## 디자인 의도와 원하는 모습

UI 에셋별로 사용자가 무엇을 알아보고 어디에 먼저 시선을 두어야 하는지 문장으로 설명한다.
[Art 디자인 기준](../../../Art/docs/agetns/design/README.md) 중 [팔레트](../../../Art/docs/agetns/design/palette.md)·[도트 스타일](../../../Art/docs/agetns/design/pixel-style.md)·[가독성](../../../Art/docs/agetns/design/readability.md)을 참고하고 실제 UI에 적용할 기준을 적는다.

- 대상 에셋·전달할 의미/인상·사용자가 바로 이해해야 할 기능:
- 의미를 표현할 사물/상징·핵심 실루엣·다른 아이콘과 구별할 형태:
- 큰 형태와 내부 구성·중심/정렬·여백·정보의 시선 순서:
- 주조색·보조색·강조색의 역할과 주변 UI/배경 대비:
- 재질감·외곽선·모서리·내부 선·픽셀 덩어리·디테일 밀도:
- 평면/입체 표현·명암·그림자/발광 사용 여부와 범위: 연구실 월드 광원을 UI 전체에 자동 적용하지 않음
- 공용 UI와 맞출 시각적 무게·반복 모티프·크기가 달라도 유지할 특징:
- 텍스트와 그림의 역할 분담·글자 주변을 비울 부분·장식의 강조 한도:

- 반드시 보일 요소 / 넣지 않을 글자·장식 / 다른 기능으로 오해할 표현:

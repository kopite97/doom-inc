- 요청 근거: 2026-10-26 사용자 승인. 루트 100줄·하위 지침 150줄 제한, 다섯 PLAN 상태와 단일 active.

- 기준: [문서 관리](../game-design/00-management/01-workflow/document-rules.md), [로드맵](../game-design/05-development/02-implementation/roadmap.md).

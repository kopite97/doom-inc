# PLAN-029 연구소 가공시설·배양시설·저장소 정식 아트 제작·적용

## 목표

연구소의 가공시설·배양시설·저장소를 문자와 색상 중심의 임시 표현에서 정식 픽셀 아트로 교체한다. 시설 이름을 읽지 않아도 **가공하는 기계 / 생명체를 배양하는 장치 / 물건을 보관하는 설비**를 실루엣으로 구분하고, 접근 위치와 점유 범위를 그림에서 이해할 수 있게 한다.

주목적은 정식 아트 제작·적용·사용자 시각 확인이므로 `type: art`다. **2026-11-12 사용자의 명시적 요청으로 active 전환하고 제작 요청서를 발행했다.** 후속 사용자 요청으로 에이전트가 Aseprite 제작을 위임받았다. 세 시설 r001의 제작·파일 검증·사용자 Art 시각 승인·PNG 수령을 완료했다. 전체 Unity 적용·일반 기술 검증 후 2026-11-12 사용자가 실제 게임 화면과 동작을 그대로 승인하고 완료 처리를 요청했다. 세 시설 r001의 적용·기술 검증·사용자 게임 화면 승인을 모두 충족해 completed로 전환했다.

## 범위

- 포함: 기존 가공시설·공용 배양시설·저장소 각 1종의 외형과 최소 인게임 애니메이션. 에셋당 한 Aseprite 스프라이트 안에서 16프레임·3태그를 만들며, 총 48프레임·PNG 시트 3개·Aseprite 원본 3개다.
- 포함: 세 시설의 지도 표시·건설/이동 미리보기·시설 목록 또는 건설 항목의 기존 이미지 참조 연결. 별도 목록 전용 아이콘은 만들지 않고 같은 Sprite를 비율 유지해 재사용한다.
- 포함: 기존 선택 테두리·배치 유효/무효·공용 건설 진행 표시·상호작용 칸·상태 표식과의 연결 및 가려짐 확인. 이 표식은 기존 별도 그래픽을 재사용한다.
- 재사용: PLAN-026의 바닥·획득시설·프로토타입·유기물·Build, PLAN-027의 Tilemap/SpriteRenderer, PLAN-028의 이동 보간·입력 게시 계약.
- 포함: 가공/배양 Idle·Working·Complete, 저장소 Idle·Receive·Send의 태그/시간과 실제 상태·성공 사건·정지/재개·세션 수명 연결. 실제 게임 규칙은 유지하며 표시용 관찰만 최소 보완한다.
- 제외: 방향별 별도 원화, 공용 건설 PNG 신규 제작, 파손 단계·업그레이드·장식 변형·시설 스킨.
- 제외: 바닥/외곽 신규 제작, 생명체·자원 추가 아트, 전체 UI·타이틀 교체, 새 시설·레시피·기능·저장 필드·밸런스·점유/접근 규칙 변경.
- 제외: 빌드 테스트 전체(APK/AAB·PC Player·Player 스크립트 컴파일·IL2CPP·Addressables 콘텐츠), 실기기 설치/검증.
- 제외: 고부하/스트레스 테스트, 대량 시설·개체·데이터를 이용한 성능 측정, 반복 벤치마크와 이를 위한 예비/추가 진단. 일반 소규모 기능·입력·저장 회귀만 계획한다.
- 이 PLAN은 아트 로드맵 5-2 중 **나머지 시설 3종**의 작업 단위다. 후속 사용자 지시로 원래 5-5에 둘 수 있었던 세 시설의 최소 가동/완료·입출고 동작도 이번 범위에 포함한다. 다른 생명체/시설·탄생/방출 전체 연출까지 5-5를 완료 처리하지 않는다. 이 범위의 완료만으로 바닥 외곽 등 모든 5-2 후보나 전체 5단계를 완료 처리하지 않는다.
- 요청 근거: 2026-11-12 사용자가 추천한 5-2의 세 시설 제작·적용을 다음 PLAN으로 구체화하되 빌드·고부하 제외와 proposed 유지를 명시했다.

- 실제 요청 ID와 예정 수령 위치는 제작 요청서에 기록했다. 리비전별 파일은 [수령 규칙](../agents/art-assets.md#request-delivery-paths)에 맞춰 발행한다. 아직 존재하지 않는 PNG·Art PLAN·요청 README를 실제 수령본으로 링크하지 않는다.
- 적용 전 [LaboratoryArtAssets](../../UnityProject/Assets/Scripts/Presentation/Gameplay/Laboratory/LaboratoryArtAssets.cs)는 획득시설/프로토타입 전용 참조만, [지도 아트 경로](../../UnityProject/Assets/Scripts/Presentation/Gameplay/Laboratory/LaboratoryMapView.Art.cs)는 해당 두 종류의 정식 표시만 판정한다. **Icon 하나 교체만으로 지도 교체가 끝났다고 보지 않는다.**
- 기존 SO/표현 경계 안에서 시설 정의→동작별 프레임/시간의 작은 바인딩과 지도/미리보기 공통 적용을 계획한다. 정의 ID·점유·상호작용 좌표는 아트 선택 기준으로 보존하고 범용 렌더러·새 싱글톤·별도 아트 재고 모델은 만들지 않는다.
- 세 시설이 정식 아트 대상으로 판정되면 기존 임시 역할 문자/채색 몸체를 대체한다. 실제 선택 테두리·접근 칸·건설/생산 상태 표식은 유지하고 그림에 중복 합성하지 않는다. 대상 외 시설/생명체의 대체 표시도 유지한다.
- 본체와 미리보기는 같은 픽셀 비율·피벗·논리 회전을 사용한다. 저장소 90/270도의 원본 크기 192×128을 128×192로 다시 늘이거나 정사각형으로 찌그러뜨리지 않는다.
- 기존 획득시설 애니메이션·프로토타입 이동/운반·입력·정렬을 보존한다. 세 시설의 현재 동작과 위상은 화면이 시설별로 소유하고 전용 성공 관찰은 실제 산출/이전 성공 지점에서 읽는다. 단순 총량 차이나 렌더 프레임 이전/이후 비교로 사건을 추측하지 않는다. 생성 도구 재실행·Title 재진입·새 판에서도 세 시설의 정식 참조를 유지한다. 원본 픽셀 변경은 사용자 수정본으로만 받는다.

# PLAN-024 침공형 방출 성공 피드백과 화면 밖 시설 선택 시 지도 이동

## 목표와 기준

플레이어가 침공형 방출 성공을 즉시 알아차리고, 목록에서 선택한 시설이 화면 밖에 있을 때 지도가 어느 방향으로 이동했는지 따라갈 수 있게 한다. 로드맵 4단계의 연구소 조작 후속 작업이다. [화면과 조작](../game-design/03-player-experience/03-interface/controls.md) · [외부 연출 에셋 사용 기준](../agents/presentation-effects.md) · [변경 검증](../agents/verification.md)

## 작업 목록

- [x] **Feel 방출 피드백.** 연구소 화면의 `ReleaseInvaders()`에서 명령 성공을 받은 직후 Feel 플레이어를 한 번 재생한다. 대기 중인 개체 수와 관계없이 한 요청에 출격음 한 번과 아이콘 강조 한 번을 함께 재생한다. 현재 방출 행은 텍스트 버튼이므로 기존 침공 메뉴 버튼의 자식 아이콘을 강조 대상으로 삼는다. 짧은 단발 출격음을 바인딩하고, 아이콘은 살짝 커졌다 원래 크기로 돌아오게 한다. 패널 갱신·저장 복원은 재생 계기가 될 수 없다. 화면 해제 시 재생을 정리한다. [방출 결과](../../UnityProject/Assets/Scripts/Presentation/Gameplay/Laboratory/LaboratoryView.cs) · [침공 버튼과 아이콘](../../UnityProject/Assets/Scripts/Presentation/Gameplay/Laboratory/LaboratoryView.Gui.cs)
- [x] **DOTween 지도 이동.** 목록에서 선택한 시설이 일부 또는 전부 화면 밖에 있으면, 기존 시설 경계와 뷰포트 계산으로 얻은 목표 중심까지 약 0.2초 동안 부드럽게 이동한다. 줌 배율을 유지하고 시설 전체가 이미 보이면 이동하지 않는다. 드래그·핀치·휠·지도 맞춤은 즉시 자동 이동을 중단한다. 새 시설을 선택하면 현재 위치에서 새 목표로 이동하고, 같은 선택의 매 프레임 갱신은 이동을 다시 시작하지 않는다. 회전·패널 크기 변경 시 새 경계를 적용하고 화면 해제 시 트윈을 정리한다. [지도 선택·입력](../../UnityProject/Assets/Scripts/Presentation/Gameplay/Laboratory/LaboratoryMapView.cs)

## 실행 결과

- 방출 명령이 성공하면 침공 메뉴 아이콘에서 Feel의 `MMF_Sound`와 `MMF_Scale`을 한 번 재생한다. 프로젝트에 포함된 약 0.18초의 `FeelDuckWoosh`를 사용하고, 약 0.2초 동안 아이콘을 강조한다. 연구소 씬과 생성 도구 양쪽에서 카메라에 AudioListener를 연결했다.
- 지도는 시설의 회전된 점유 범위와 현재 뷰포트로 목표 중심을 정하고 DOTween으로 0.2초간 이동한다. 수동 이동·확대·축소·맞춤은 이동을 중단하고 새 선택·화면 회전은 현재 중심에서 목표를 다시 계산한다. 두 연출 모두 기존 화면의 수명에 연결했다.
- Unity 6000.3.27f1 Editor Play Mode에서 동시 2마리 방출, 대기 없음, 일시정지 중 거절, 다음 성공, 실제 AudioSource 재생과 종료, 아이콘 확대와 원상 복귀를 확인했다. 지도는 1280×720과 720×1280에서 이미 보이는 대상, 화면 밖 대상, 드래그 중단, 연속 선택·화면 회전·줌·맞춤을 확인했다.
- 첫 연구소 회귀 실행은 31/32로 엔딩 회전 중 요청 객체 동일성 검사 한 건이 실패했다. 후속 실행과 최종 실행은 각각 33/33 통과했다. [첫 실행](evidence/PLAN-024/play-first.json) · [최종 실행](evidence/PLAN-024/play-final.json)

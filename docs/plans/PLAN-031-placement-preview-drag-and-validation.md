# PLAN-031 건설·시설 이동 미리보기 드래그와 배치 오류 안내

## 목표

신규 건설과 기존 시설 이동을 시작하면 즉시 화면에 미리보기가 나타나고, 미리보기 건물을 드래그해 위치를 조절할 수 있다. 배치할 수 없는 경우 문제가 되는 칸과 구체적인 이유를 함께 보여준다.

## 범위

- 포함: 미리보기 건물 드래그 이동, 편집 진입 직후 보이는 초기 미리보기, 점유·충돌·영역 밖 칸 표시, 배치 불가 이유와 확정 가능 상태 동기화.
- 포함: 신규 건설·기존 시설 이동의 공통 조작, 네 방향 회전 후 판정 갱신, 마우스·터치·가로·세로 대응, ko/en 문구와 필요한 일반 Editor 검증.
- 제외: 화면 가장자리 자동 스크롤, 새로운 입구 화살표·접근 경로 경고, 연속 건설·자동 빈자리 검색·드롭 즉시 확정, 건설 목록에서 지도까지 끌어놓기.
- 제외: 비용·건설 시간·통로 차단 허용·일시정지·저장 규칙 변경, 신규 Sprite 제작, 외부 에셋 추가 도입, Player/Android 빌드·실기기·고부하·성능 계측.
- 요청 근거: 2026-11-15 사용자가 드래그 이동·건설 선택 직후 미리보기·충돌 칸과 배치 불가 이유를 포함한 PLAN 작성을 요청하고 기존 시설 이동에도 동일 적용하도록 지정했다. 이후 사용자가 PLAN을 승인하고 작업 시작을 요청했다.

## 구현 설계

### 초기 미리보기

- 신규 건설: 건설 종류 선택 후 편집 패널 전환으로 정해진 실제 지도 뷰포트 중앙에 건물 중심이 오도록 후보 원점을 격자에 맞춘다. 시설 전체가 지도에 들어갈 수 있다면 경계 안으로 보정한다.
- 최초 후보가 다른 시설과 겹쳐도 숨기거나 자동으로 다른 빈자리를 찾지 않는다. 즉시 빨간 문제 칸과 이유를 표시해 사용자가 조절한다. 시설이 지도보다 큰 경우도 배치 불가 미리보기로 남긴다.
- 기존 시설 이동: 원래 위치·방향으로 즉시 미리보기를 표시한다. 화면 밖이면 시작 시 한 번 보이도록 지도를 조정한다. 이동 시작만으로 후보를 화면 중앙의 다른 칸에 옮기지 않는다.
- 초기 위치·가시성 처리는 편집 진입마다 한 번만 한다. 회전·줌·언어/화면 방향 변경·패널 갱신 때 사용자가 정한 후보 위치를 초기화하지 않는다.

### 드래그와 입력 우선권

| 입력 | 동작 |
| --- | --- |
| 미리보기에서 시작한 마우스/한 손가락 드래그 | 잡은 위치와 건물 원점 사이 간격을 유지하며 격자 단위로 후보 이동 |
| 빈 지도에서 시작한 드래그 | 기존 지도 이동 유지; 도중에 미리보기를 지나도 건물 드래그로 바뀌지 않음 |
| 지도 클릭·탭 | 기존 위치 지정 유지; 편집 중 일반 선택·선택 해제를 실행하지 않음 |
| 두 손가락 이동·핀치, 마우스 휠 | 지도 이동·줌. 건물 드래그 중 두 번째 손가락이 들어오면 마지막 후보를 유지하고 지도 조작으로 전환 |
| 드래그 종료 | 마지막 후보 유지. 실제 적용은 기존 확정 버튼으로만 수행 |
| UI 위에서 시작한 입력 | 지도·건물 드래그를 시작하지 않음 |

- 미리보기 잡기 판정은 화면에 표시한 본체/점유 영역을 기준으로 하며 작은 대상은 필요한 최소 터치 여유를 둔다. 실제 원점에 대한 잡은 지점 간격을 유지해 시작 순간 위치가 튀지 않게 한다.
- 포인터가 UI 위나 지도 뷰포트 밖으로 나가면 후보 갱신을 멈추고 마지막 위치를 유지한다. 같은 드래그로 지도에 돌아오면 다시 갱신하며, 놓을 때 뒤 UI 버튼을 실행하지 않는다.
- 지도 뷰포트 안의 포인터로 계산한 후보가 지도 경계를 넘으면 무조건 안쪽으로 고정하지 않는다. 영역 밖인 후보와 이유를 보여주며 확정을 막는다. 최초 배치의 경계 보정과 드래그 중 오류 안내를 구분한다.
- 핀치 후 남은 손가락은 새 탭/건물 드래그로 재해석하지 않는다. 포인터를 모두 놓은 뒤 새 조작을 시작한다.
- 입력 취소·포커스 상실·화면 방향 변경·편집 종료·세션 교체는 드래그 소유권을 해제한다. 늦게 도착한 Up이 확정·선택·새 후보 갱신을 일으키지 않게 한다.

### 문제 칸과 이유 표시

- 미리보기의 점유 칸을 옅게 표시하고, 다른 시설과 겹치는 칸 및 영역 밖 칸은 빨간색으로 구분한다. 기존 외곽 테두리의 전체 가능/불가 표시와 확정 버튼도 같은 판정에 맞춘다.
- 시설 이동에서는 대상 자신의 기존 점유 칸을 충돌로 세지 않는다. 생명체와의 겹침·통로 차단·상호작용 위치 접근 불가는 기존 규칙대로 새 배치 금지 조건에 추가하지 않는다.
- 원점·회전이 바뀔 때 문제 칸과 이유를 함께 갱신한다. 회전 시 가로/세로 점유 크기를 반영하며 이전 칸 표시를 제거한다. 편집 종료·취소·세션 교체 시 표시를 정리한다.
- 화면에 보이는 후보의 문제 칸을 표시한다. 지도 밖 후보 칸도 뷰포트 범위에서 표현하되 UI 밖으로 그리지 않는다. 화면 밖 문제는 텍스트로도 설명한다.
- 이유는 기존 PlacementError에 대응하는 Localization 메시지로 표시한다. 예: “다른 시설과 겹칩니다”, “건설 영역 밖입니다”. 영역 밖과 겹침이 동시에 있으면 문제 칸은 모두 표시하고 대표 이유는 기존 판정 우선순위인 영역 밖 → 겹침을 따른다.
- 위치 외의 오류는 원인을 왜곡하는 빨간 임의 칸을 만들지 않는다. 해당 상황에 맞는 번역된 안내 또는 일반 오류를 표시하며 enum·영문 내부 오류 문자열을 그대로 노출하지 않는다.
- ko/en CSV와 테이블을 함께 갱신하고 색 외에 텍스트로 구분한다. 드래그 중 매 프레임 알림을 새로 띄우지 않고 편집 안내 영역을 갱신한다. 유효 위치로 돌아오면 오래된 실패 이유를 지운다.

### 책임과 공통화

- 근거: 신규 건설과 시설 이동 모두 같은 후보 크기·회전·배치 규칙·피드백을 사용한다. 입력·칸 표시·메시지를 두 경로에 복제하면 회전/자기 제외 판정이 달라질 위험이 있다.
- 입력 시작 위치와 조작 종류는 표현 계층이 소유한다. 기존 Gesture의 화면 입력 해석과 MapView의 히트 판정·명령 호출 경계를 유지하며 드래그 이동과 지도 이동을 명시적으로 구분한다.
- 후보 갱신은 기존 View.PreviewAt/RotatePreview와 공통 명령을 사용한다. 건설 비용·확정과 기존 시설의 상태 보존·즉시 이동은 각 기존 도메인 경로에 남긴다.
- 칸별 진단은 기존 공간 판정과 동일한 기하·자기 제외 규칙을 재사용하는 최소 조회로 제공한다. Presentation에서 독자적인 배치 금지 규칙을 다시 만들지 않는다. 최종 확정 시 기존 명령이 재검사한다.
- 후보가 같은 칸에 머물면 불필요한 명령·문구·표시 객체 재생성을 피한다. 표시 객체는 편집 화면 수명에 맞춰 재사용·해제한다. 범용 드래그 프레임워크·싱글톤·미래 효과용 추상 계층은 추가하지 않는다.
- 줄어들 작업: 같은 조작·진단 검증을 건설/이동 두 경우에 적용해 공통 수정 누락을 막는다. 구체 API와 작은 객체 분할은 구현 중 위임된 상세로 결정하고 결과를 기록한다.

## 최종 구현과 기술 선택

- 기존 LaboratoryGesture에 드래그 시작 시 포착 여부를 결정하는 콜백과 절대 위치 드래그 이벤트를 추가했다. 입력 수명은 기존 Gesture가 유지하고, 미리보기 히트 판정·잡은 지점 간격·좌표 변환은 [MapView.Placement](../../UnityProject/Assets/Scripts/Presentation/Gameplay/Laboratory/LaboratoryMapView.Placement.cs)가 담당한다.
- 편집 진입 때 초기화 요청을 남기고 실제 레이아웃이 반영된 PublishFrame에서 한 번 적용한다. 신규 건설은 중앙 후보를 경계 안으로 보정하고, 기존 이동은 원래 좌표를 유지하며 필요할 때 한 번 보여준다. 직접 PreviewAt으로 이미 정한 후보는 지연 초기화가 덮어쓰지 않는다.
- GridMap.CheckPlacement에 선택적인 문제 칸 목록을 받도록 확장했다. 기존 CheckGeometry의 경계·교차·자기 제외 판정에서 목록을 채우므로 확정 규칙을 표현 계층에 복제하지 않는다. 오류 우선순위와 기존 호출 계약을 유지한다.
- 칸 오버레이는 기존 미리보기 루트 아래 SpriteRenderer로 재사용한다. 원점·방향·대상·지도 배치 버전이 바뀔 때 진단을 갱신하고, 회전 후 남는 칸은 숨긴다. 미리보기 종료 시 루트와 함께 숨기며 세션 해제 시 같이 제거한다.
- 소유·형태: 화면 입력·표시 상태는 기존 MapView MonoBehaviour 인스턴스 수명에 두고, 공간 진단은 기존 GridMap 일반 객체의 조회다. 새 싱글톤·외부 에셋·별도 게임 상태·저장 필드는 추가하지 않았다.
- 제품 텍스트는 기존 편집 안내 영역을 사용한다. CSV 원본과 생성 테이블을 함께 갱신했고 기존 시설 이동의 정상 문구도 자재 운반 대신 즉시 이동으로 구분했다.
- 자세한 결과·화면·초기 실패와 수정·재현 방법은 [검증 증거](evidence/PLAN-031/README.md)를 따른다.

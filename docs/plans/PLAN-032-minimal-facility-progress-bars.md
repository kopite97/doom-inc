# PLAN-032 모바일 시설 상태 표시를 작은 읽기 전용 진행 바로 단순화

## 목표

시설 위 상태 표시를 얇은 배경 막대와 진행량만 있는 작은 바 하나로 통일한다. 바는 클릭·탭·설명 확장·표시 전환 조작 없이 현재 상태를 계속 보여주며, 상세 정보는 기존 시설 선택 패널에서 확인한다.

## 범위

- 포함: 작은 진행 바와 얇은 배경의 크기·대비·배치 조정, 지도 위 상태 아이콘·문구·퍼센트·배경 카드·연결선 제거, 선택·줌에 따른 확대/설명 표시 제거.
- 포함: 바 전용 클릭·탭 판정과 설명 확장 제거, 지도 툴바·설정 팝업의 시설 상태 ON/OFF 조작 제거, 이전 OFF 설정과 무관한 상시 상태 표시, 남는 툴바 공간 정리.
- 포함: 건설·획득·가공·배양의 공통 표시, 진행/대기 구분, 가로·세로·줌·큰 글씨 대응, 시설 선택 상세 및 기존 배치 입력 보존, 관련 테스트 갱신.
- 제외: 시설 본체 선택·상세 패널의 조작 제거, 생산/건설 규칙·저장 진행 데이터 변경, 경고 아이콘·툴팁·팝업·반짝임·새 애니메이션 추가, 신규 Sprite·외부 에셋 도입.
- 제외: Player/Android 빌드·실기기·고부하·성능 계측. 일반 Editor 기능 검증과 실제 렌더링 확인으로 범위를 한정한다.
- 요청 근거: 2026-11-15 사용자가 모바일에서 시설 상태 표시를 간결한 진행 바 하나로 줄이고 얇은 배경도 조정하도록 요청했다. PLAN 작성 중 “조작기능도 그냥 없애줘. 프로그레스바는 그냥 상태만 계속표현하게 하자”라고 지정했다. 이후 사용자가 PLAN 실행을 승인했다.

## 구현 설계

### 작은 막대와 얇은 배경

- 시설 하나당 Track과 Fill로 이루어진 가로 막대 하나만 둔다. 큰 배경 카드·상태 아이콘·텍스트·퍼센트·연결선·장식 테두리·그림자·Glow는 두지 않는다.
- 초기 비교값은 **전체 배경 포함 36×4 UI 단위**다. 가로 길이·전체 높이·배경 밝기/불투명도·채움 대비는 모바일 비율의 실제 화면에서 조정하는 위임값이다. 조정한 최종 값을 PLAN과 화면 증거에 남긴다.
- 배경은 미충전 구간을 식별할 정도의 어두운 단색으로 한다. 배경이 막대 밖으로 크게 튀어나오거나 별도 상자처럼 보이지 않게 한다. 채움은 배경 안에서 수평으로 증가하며 0%·부분·100%가 구분돼야 한다.
- 얇다는 이유로 저해상도에서 흐려지거나 사라지지 않도록 Canvas 스케일과 화면 픽셀 정렬을 확인한다. 기기 물리 픽셀과 UI 단위를 혼동하지 않는다.
- 줌·선택·큰 글씨 설정으로 막대를 확대하거나 글자를 추가하지 않는다. UI 스케일링은 따르되 지도 줌과 독립된 일정한 작은 화면 크기를 유지한다.
- 시설 상단 가까운 일정한 위치에 둔다. 기존 화면 전체 빈자리 탐색과 먼 위치로 옮긴 표식의 연결선을 제거한다. 회전·카메라 이동에 맞춰 앵커만 갱신한다.
- 화면 밖 시설의 바를 화면 가장자리로 끌어와 모으지 않는다. 지도 뷰포트에서 클리핑하고 UI 패널을 덮지 않는다. 인접 시설의 표시가 겹치지 않는 크기·간격을 일반 배치 사례에서 검증한다. 밀도에 따라 아이콘으로 바꾸거나 일부 바를 임의로 숨기지 않는다.

### 계속 표시할 상태

| 상태 | 표시 |
| --- | --- |
| 건설·수집·생산 진행 중 | 작은 기본색 진행 바. 현재 ProgressFraction 반영 |
| 자동 생산 | 같은 기본색·크기 사용. 자동 생산 전용 아이콘/별도 바를 추가하지 않음 |
| 자재·작업자·대상 지정·접근·산출물 처리 대기 | 현재 진행량을 유지하고 같은 막대의 색조를 주황 계열로 구분 |
| 진행량 0인 대기 | 진행량을 거짓으로 채우지 않는다. 얇은 Track의 색조로 대기 상태가 남아 보이게 함 |
| 산출물 회수 대기 | 기존 ProgressFraction=1을 그대로 표시하며 대기 색조 적용 |
| 연구소 전체 일시정지·배치 편집 | 기존 진행량과 시설별 상태 표시 유지. 전역 정지를 시설 고장/접근 불가로 바꾸지 않음 |
| 완공 저장소 등 HasProgress=false | 바 없음. 건설 중 저장소는 건설 바 표시 |

- 진행 상태를 색 이외의 추가 지도 요소로 설명하지 않는다. 색을 구별하기 어려워도 정확한 상태·진행률·대기 이유는 기존 시설 상세 패널에서 확인할 수 있어야 한다.
- 연구소 화면에 보이는 진행 대상은 선택 여부·줌과 무관하게 계속 표시한다. 화면 종료·대상 제거·세션 교체 시 표시를 정리한다.

### 조작 제거와 기존 입력 유지

- 바는 읽기 전용이다. 클릭·탭·재탭·드래그·호버에 반응하지 않으며 설명 확장, 시설 선택 대신 처리하는 상태 표식 히트 영역, 투명한 추가 터치 영역을 두지 않는다.
- Track/Fill의 RaycastTarget을 끄고 TrySelectStatus 및 CaptionOverride 등 전용 입력/확장 상태를 제거한다. 바 위 입력은 아래 시설·빈 땅·편집 미리보기의 기존 판정에 전달된다.
- 따라서 바가 시설 위에 겹치면 아래 시설이 선택될 수 있고, 빈 땅 위에 있으면 일반 지도 선택 해제 또는 지도 드래그가 수행된다. 바 자체를 선택한 결과로 해석하지 않는다.
- 지도 툴바와 설정 팝업에서 시설 상태 표시 ON/OFF 조작을 제거한다. 툴바는 남은 줌·맞춤 조작에 맞게 재배치하고 빈 버튼 자리를 남기지 않는다.
- 이전 사용자 설정에 ShowFacilityStatus=false가 저장되어 있어도 바는 표시한다. 기존 설정 파일 읽기를 깨지 않게 하고, 사용되지 않는 필드의 호환 보존 또는 최소 정리는 구현에서 기록한다. 한 판 저장 형식 변경이나 전체 설정 초기화는 하지 않는다.
- 큰 글씨·언어·다른 환경 설정과 시설 상세 패널은 유지한다. 제거된 표시 전환에서 나오던 ON/OFF 피드백도 더 이상 제품 화면에 표시하지 않는다.
- 사용하지 않게 되는 아이콘·번역 키는 다른 참조를 확인한다. 공용 에셋을 일괄 삭제하지 않으며 CSV 변경이 필요하면 원본·검토·테이블 절차를 따른다.

### 책임·수명·공통화

- 건설·수집·가공·배양 모두 기존 FacilityStatusQuery 결과를 같은 바 표현 경로에 연결한다. 색·진행률 계산을 종류별 화면에 복제하지 않는다.
- 상태 원본·생산 규칙은 기존 도메인에 유지한다. 표현은 기존 MapView의 화면 수명과 시설 ID를 사용하며 표시 객체를 재사용하고 시설 제거/화면 종료 때 정리한다.
- 기존 복합 표식·빈자리 탐색·설명/선택 전용 캐시를 축소한다. 범용 진행 바 시스템·새 인터페이스·싱글톤·새 Shader를 추가하지 않는다.
- 공통화 근거는 여러 시설 종류가 같은 진행/대기 표현을 사용한다는 점이다. 작은 상태→색 매핑과 기존 화면 객체로 충분하며, 변경할 책임과 검증 범위를 줄이는 방향으로 구현한다.

## 기본 화면과 선택 패널 (D-006·D-067)

연구소 기본 화면을 중심으로 운영하며, 시설·생명체를 선택하면 해당 대상의 설정과 상태를 확인하는 패널을 연다. 연구소 화면은 줌인·줌아웃할 수 있다(S1-B-04). 전과 보고는 필요할 때 펼쳐 본다.

| 구성 | 표시와 조작 범위 |
| --- | --- |
| 연구소 기본 화면 | 연구소, 자원·개체 수, 멸망 게이지를 확인하고 건설·방출을 실행한다. |
| 시설·생명체 선택 패널 | 선택한 대상에 해당하는 시설 이동·회전, 작업 배정, 배양 대상 선택, 저장 허용 자원 설정을 제공한다. 작업 상태와 대기 이유도 보여준다. |
| 펼쳐 보는 전과 보고 | 연구소 화면에서 필요할 때 전과 보고를 펼쳐 확인한다. 표시·열람 여부와 성과 누적은 별개다. |

조작은 해당 시설·생명체에 승인된 기능에만 적용한다. 배정·작업 전환은 [보조형 모델](../../02-systems/05-creatures/support-models.md), 배양 선택은 [생산시설](../../02-systems/01-production/facilities.md), 저장 설정은 [저장과 운반](../../02-systems/02-logistics/storage-and-transport.md)의 규칙을 사용한다.

## 가로·세로 지원 (D-090)

**프로토타입에서도 가로·세로 화면을 모두 지원한다. 가로 화면에서 기본 게임 사이클을 먼저 완성한 뒤 세로 대응을 추가한다.**

- 두 방향에서 같은 기능과 화면 요소를 유지한다. 기존 연구소 기본 화면·시설과 생명체 선택 패널·전과 보고를 함께 사용한다.
- 화면 방향에 따라 기존 요소를 재배치하는 수준으로 대응한다. 방향별 게임 규칙이나 전용 기능을 추가하지 않는다.
- 가로에서 초기 건설부터 생산·침공·한 판 종료와 다시 시작까지 연결한 뒤 세로 대응을 추가한다. 최종 검증에서는 두 방향을 모두 확인한다.

단계별 순서는 [구현 계획](../../05-development/02-implementation/roadmap.md), 실제 Android 기기 검증은 [플레이 환경](../../04-delivery/01-platform/environment.md)을 따른다. 실제 구현·검증은 아직 수행하지 않았다.

## 시간 흐름과 결과 화면 (D-033·D-064)

시설 배치·이동·회전의 위치와 방향을 고르는 동안 연구소 진행을 일시정지하고, 확정하거나 취소하면 재개한다. 상태·작업·예약 유지와 재개 규칙은 [시설 배치](../../02-systems/03-space/placement.md)를 따른다.

멸망 게이지가 가득 차면 연구소와 외부 활동의 진행을 멈추고, 간단한 멸망 연출 후 결과 화면을 표시한다. 플레이어가 ‘다시 시작’을 선택하면 초기 상태로 돌아간다. 진행 정지 중에도 연출과 화면 표시는 동작한다. 한 판 종료·재시작은 [목표와 반복 흐름](../../01-direction/02-experience/core-loop.md), 단계 전환 책임은 [GameFlow](../../05-development/01-architecture/game-flow.md)를 따른다.

여러 세계 진행·환생·영구 보너스는 현재 결과 화면에 포함하지 않는다. 전체 포함·후속 범위는 [최초 제공 범위](../../04-delivery/02-release/scope.md)에서 관리한다.

## 화면과 로직 연결 및 개발 위임 (D-059·D-079)

화면의 조작과 상태 표시는 플레이 화면·하네스의 공통 명령 처리·규칙 검사·상태 조회를 사용한다. 상태 원본과 구조의 정식 기준은 [Thing과 정의 데이터](../../05-development/01-architecture/thing-model.md)를 따른다.

버튼 위치·크기, 패널 배치, 화면 비율 대응, 카메라 표시 범위, 방향 전환 처리, 연출·결과 화면의 표현과 세부 조작 구현은 개발하면서 정한다. 실행·저장 규칙은 [플레이 환경](../../04-delivery/01-platform/environment.md)을 따른다.

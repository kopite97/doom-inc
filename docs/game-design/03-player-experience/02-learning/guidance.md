## 학습과 피드백

시설의 역할, 배치의 중요성, 병목 해결을 학습하는 경험을 지향한다(D-001).

시설·생명체 선택 패널에서 작업 상태와 대기 이유를 표시해 현재 동작을 파악할 수 있게 한다(D-067). 표시 항목과 조작의 정식 범위는 [화면과 조작](../03-interface/controls.md)에서 관리한다.

실제 플레이로 대표적인 병목을 파악하고, 배치·배정·저장 설정 등을 바꿔 개선할 수 있는지 확인한다(D-070). 병목의 관점은 [병목 해결](../../02-systems/04-optimization/bottlenecks.md), 최종 판정은 [프로토타입 완료 기준](../../04-delivery/02-release/scope.md)을 따른다. 실제 검증은 아직 수행하지 않았다.

## 개발 위임과 미확정 범위

문구·표현·배치와 구체적인 검증 반복 횟수는 개발하면서 정한다(D-059·D-070). 별도 튜토리얼 도입은 확정하지 않았으며, 기본 상태 피드백과 구분한다.

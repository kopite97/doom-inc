# 결정 기록

- 갱신일: 2026-10-26
- 역할: 승인 근거와 대체 관계를 찾는 색인. 구현은 각 항목의 **현행 담당 문서**를 기준으로 한다.
- D-001~D-090은 기존 식별자를 유지한다. 결정 번호가 크다는 이유만으로 다른 규칙을 덮어쓰지 않는다.
- 현재 효력: **유효**는 적용 중, **부분 대체**는 일부만 후속 결정으로 변경, **대체**는 현재 구현에 적용하지 않는 이력, **절차 이력**은 기획 진행 과정의 기록이다.
- 아래 요약은 결정의 범위를 찾기 위한 안내다. 생략된 상세를 폐기한 것으로 해석하지 않으며, 상세 규칙과 개발 위임 범위는 연결된 주제 문서에서 확인한다.
- 설치·구현·검증의 실제 기록은 [작업 PLAN](../../../plans/README.md), 주요 기술 선택은 [기술 결정](../../../decisions/README.md)에서 관리한다. 전체 단계·완료 기준은 [구현 계획](../../05-development/02-implementation/roadmap.md)을 따른다.

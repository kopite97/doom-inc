## 범위와 역할

이 문서는 생산시설의 레시피, 회차 상태, 재료 소비, 생산 속도, 완료 처리와 배양 선택의 정식 규칙을 관리한다. 새 생산시설을 건설하며 각 시설의 역할을 학습한다(D-001·D-009).

| 시설 역할 | 프로토타입 시설 | 결과 |
| --- | --- | --- |
| 자원 생산 | 기초 자원 획득 시설 | 기초 자원인 유기물 |
| 재료 가공 | 재료 가공시설 | 가공 재료인 배양액 |
| 생명체 배양 | 공용 생명체 배양시설 | 선택한 종류의 보급형 또는 침공형 |

유기물·배양액은 가칭이다. 보급형과 침공형은 같은 종류의 배양시설을 사용한다(D-036·D-039). 전체 콘텐츠와 시작 상태·생산 진입 흐름은 [프로토타입 범위](../../04-delivery/02-release/scope.md), 저장소는 [저장과 운반](../02-logistics/storage-and-transport.md), 건설·이동은 [시설 배치](../03-space/placement.md), 개체 배정·작업 선택은 [보조형 모델](../05-creatures/support-models.md)을 따른다.

## 현재 레시피와 기준 시간

다음 값은 승인된 프로토타입 초기 시험값이다(D-042·D-044·D-046·D-058).

| 시설 / 선택 대상 | 회당 투입 | 회당 산출 | 개체가 실제 작업할 때 | 실제 작업자 없이 20%로 진행할 때 |
| --- | --- | --- | --- | --- |
| 기초 자원 획득 시설 | 없음 | 유기물 5개 | 수집 5초 | 진행하지 않음 |
| 재료 가공시설 | 유기물 5개 | 배양액 1개 | 가공 10초 | 가공 50초 |
| 공용 배양시설 / 보급형 | 배양액 2개 | 보급형 1개체 | 배양 20초 | 배양 100초 |
| 공용 배양시설 / 침공형 | 배양액 2개 | 침공형 1개체 | 배양 20초 | 배양 100초 |

시간은 해당 속도로 한 회차를 계속 진행한 경우의 값이다. 이동·재료 준비·운반·완료품 입고 대기·접근 불가·연구소 일시정지 시간은 포함하지 않는다. 중간에 실제 작업 상태가 바뀌면 남은 진행분에 현재 속도를 적용한다. 획득량이 운반량이나 동시 작업 인원을 뜻하지 않으며, 여러 개체의 속도를 합산하는 규칙은 정하지 않았다.

<a id="production-cycle"></a>

## 가공·배양의 공통 회차 규칙

D-043·D-045·D-050·D-058의 현재 유효 규칙은 다음과 같다.

1. 배정 여부와 관계없이 준비 가능한 **현재 한 회차의 재료**를 공급한다. 이미 도착한 재료와 유효한 입고 예약을 제외한 부족분만 요청한다. 배양 대상이 ‘선택 없음’이면 공급·배양을 시작하지 않는다.
2. 한 회차분 재료가 모두 도착하고 시작 조건이 충족되면 그 회차의 재료를 소비하고 자동으로 생산을 시작한다. 개체의 실제 작업 시작을 기다리지 않는다.
3. 배정된 보급형이 고정 상호작용 위치에서 실제 작업할 때는 기준 속도 100%로 진행한다. 실제 작업자가 없거나 배정 개체가 이동·운반 등 다른 일을 하는 동안에는 20%로 진행한다. 두 속도를 합산하지 않는다.
4. 속도가 바뀌어도 진행도와 투입 상태를 보존한다. 이미 시작한 회차의 재료를 다시 요구하거나 소비하지 않는다.
5. 고정 상호작용 위치에 접근할 수 없거나 연구소가 일시정지하면 생산을 멈춘다. 조건이 회복되면 보존된 상태에서 이어간다.
6. 작업 중이거나 이전 자원 완료품의 입고를 기다리는 동안 다음 회차분을 미리 비축하지 않는다.

재료는 저장소에서 공급하고 자원 결과물은 저장소로 보낸다. 시설에 한 회차분 재료를 준비하거나 해당 회차 완료품을 보관하는 상태는 허용하지만, 여러 회차의 자체 입출력 재고를 쌓지 않는다. 공급·운반량·예약·경로 예외는 [물류 규칙](../02-logistics/storage-and-transport.md)을 따른다.

<a id="gathering"></a>

## 기초 자원 획득

기초 자원 획득 시설은 별도 고정 배정 없이 수집 가능한 보조형이 자동 수집 작업으로 이용한다. 시작 프로토타입 모델도 참여할 수 있다(D-014·D-041·D-056·D-057).

- 개체가 작업 우선순위에 따라 작업을 선택하고 고정 상호작용 위치에서 실제 수집 시간을 채우면 유기물이 생성된다.
- 투입 재료가 없고, 개발 프로토타입에서는 자원이 고갈되지 않는다.
- 무인 자동 수집은 하지 않는다. 연구소 일시정지 중에는 수집 작업시간도 진행되지 않는다.
- 완료된 유기물은 저장소로 운반한다. **해당 회차의 완료품이 모두 저장소에 실제 입고된 뒤** 다음 획득 회차를 시작한다. 운반자가 집어 든 것만으로 재개하지 않는다.
- 보관할 곳이 없으면 완료품은 시설에서 기다린다. 여러 회차분을 쌓지 않는다.

수집 중 배정 변경·해제로 중단할 때의 상태 보존과, 담당 작업이 가능해졌을 때 현재 수집 회차를 마친 뒤 재선택하는 조건은 [개체 행동 전환](../05-creatures/support-models.md#assignment-change)을 따른다. 개체의 재선택과 시설의 다음 회차 시작 조건은 별개다.

<a id="processing"></a>

## 재료 가공

보급형을 배정하면 고정 상호작용 위치에서 가공 작업을 수행할 수 있다. 미배정 상태를 포함한 재료 공급·소비·속도 전환은 [공통 회차 규칙](#production-cycle)을 따른다(D-043·D-044·D-058).

회차 진행이 끝나면 배양액을 생성한다. 해당 회차의 배양액이 **모두 저장소에 실제 입고된 뒤** 다음 회차를 준비한다. 입고 대기 중 다음 회차 재료를 미리 비축하지 않는다. 재료 도착만으로 개체의 진행 중 정상 운반을 중단하지 않으며, 개체의 작업 전환은 [보조형 운용 규칙](../05-creatures/support-models.md)을 따른다.

<a id="cultivation"></a>

## 공용 배양

### 대상 선택과 회차 시작

- 시설마다 보급형 또는 침공형 중 한 종류를 선택해 반복 배양한다. 한 회차에는 선택한 종류 1개체를 만든다(D-046·D-048).
- 처음 제공되거나 새로 추가한 시설은 ‘선택 없음’이다. 대상을 선택하기 전에는 재료 공급과 배양을 시작하지 않는다(D-051).
- 선택 후에는 [공통 회차 규칙](#production-cycle)에 따라 재료를 소비하며 회차를 시작한다.
- 선택을 바꿔도 이미 시작한 회차의 종류·진행 상태를 유지한다. 변경된 선택은 다음에 시작하는 회차부터 적용한다. 현재 회차가 일시정지 중인 경우에도 동일하다.
- 이미 선택한 대상을 다시 해제하거나 별도의 배양 중지 조작을 제공하는 기능은 확정하지 않았다.

### 완료·출현과 다음 회차

배양 완료 시 해당 회차 종류의 생명체 1개체가 시설의 고정 상호작용 위치에 자동으로 출현한다(D-049·D-050).

| 항목 | 현재 규칙 |
| --- | --- |
| 수령 | 별도의 수령 조작이나 운반이 필요하지 않다. |
| 출현 위치 | 기존 생명체와 겹쳐 출현할 수 있다. 작업 중인 보급형이 있다는 이유로 기다리지 않는다. |
| 보급형 | 미배정 상태로 합류해 자동 수집·운반에 참여한다. |
| 침공형 | 연구소에서 방출 대상으로 대기한다. |
| 다음 회차 | 출현 처리가 끝나면 다음 한 회차분을 준비한다. 개체의 이동·방출을 기다리지 않으며, 현재 회차 완료 전 사전 비축은 하지 않는다. |

배양된 생명체에 자원 완료품의 저장소 입고 조건을 적용하지 않는다. 다음 회차도 선택·재료·접근 조건과 공통 소비·속도 규칙을 따른다. 겹쳐 출현이 같은 시설의 동시 작업 인원을 정하는 것은 아니다. 침공형의 방출·외부 활동은 [목표와 반복 흐름](../../01-direction/02-experience/core-loop.md)에서 관리한다.

<a id="state-preservation"></a>

## 이동·배정 변경과 상태 보존

- 시설 이동으로 회차 진행도·투입 상태를 초기화하거나 재료를 다시 소비하지 않는다. 시설에 남은 해당 회차 완료품도 보존한다. 세부 이동 처리는 [시설 이동 규칙](../03-space/placement.md#facility-movement)을 따른다(D-032).
- 개체의 배정 변경·해제로 실제 작업이 중단돼도 진행도·투입 상태는 시설에 남는다. 가공·배양은 공통 조건이 충족되면 20% 생산을 적용한다(D-053·D-058).
- 재료 공급 중 배정이 해제돼도 기존 예약·운반·도착 재료를 유지한다. 부족분 계산과 미배정 공급 조건은 공통 회차 규칙을 따른다(D-054·D-058).
- 경로 차단·시설 변경으로 완료품을 나눠 입고해도, 획득·가공시설은 해당 회차의 전량 실제 입고를 기다린다(D-022).

<a id="development-details"></a>

## 개발 중 결정할 상세

D-059에 따라 동시 작업 인원, 구체적인 작업 처리, 세부 자료구조와 시험값의 미세 조정은 개발하면서 결정한다. 현재 회차만 준비하기, 재료 한 번 소비하기, 자원 완료품 전량 입고와 생명체 출현의 구분 등 승인된 핵심 규칙은 유지한다. 건설 비용·초기 자원 지급과 전체 콘텐츠 범위는 각각 [시설 배치](../03-space/placement.md), [프로토타입 범위](../../04-delivery/02-release/scope.md)를 따른다.

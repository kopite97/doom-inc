## 모델과 기능

이 문서는 보조형의 기능, 작업 우선순위, 시설 배정과 개체 행동 전환의 정식 규칙을 관리한다. 모든 상위 모델은 하위 모델의 기능을 수행하며, 순서는 프로토타입 → 보급형 → 고급형 → 특화형이다(D-014·D-057).

| 모델 | 기능 |
| --- | --- |
| 프로토타입 | 운반·자원 수집(채굴·채광 등)·건설. 생산시설 작업자로 배정할 수 없다. |
| 보급형 | 하위 기능과 생산시설 작업자 배정. |
| 고급형 | 모든 하위 기능을 수행하며 보급형의 기능이 강화된다. |
| 특화형 | 모든 하위 기능과 추가 특수 기능. 특수 기능의 내용은 미정이다. |

시설에 **작업자로 배정**하는 기능과 시설을 **건설**하는 기능은 구분한다. 모든 보조형은 건설할 수 있으며 건설 방식은 [시설 배치](../03-space/placement.md#construction)를 따른다. 모델 간 기능 상속은 기존 개체를 상위 모델로 업그레이드하는 시스템을 뜻하지 않는다.

모델명 ‘프로토타입’과 개발 단계의 프로토타입은 다른 의미다. 개발 프로토타입에 포함할 생명체·시작 개체 수·배양 대상과 시작 자원은 [프로토타입 범위](../../04-delivery/02-release/scope.md)에서 관리한다. 시작 모델은 시설 생산 작업에 배정하지 않는다(D-056·D-057).

## 작업 우선순위와 자동 작업

플레이어가 작업 우선순위를 설정하고, 같은 우선순위이면 목록 앞의 작업을 먼저 선택한다. 기본 프리셋과 개체별 설정을 함께 사용한다. 같은 종류에서는 가까운 작업을 기본 선택하며, 운반의 거리·후보 선택 규칙은 [저장과 운반](../02-logistics/storage-and-transport.md#transport-selection)을 따른다(S1-B-08·09 / D-012).

- 프로토타입 모델은 자동 수집·운반을 수행하며 생산시설의 고정 작업자로 배정하지 않는다.
- 시설에 미배정된 보급형·고급형과 담당 시설에서 작업할 수 없는 배정 개체는 기존 우선순위에 따라 자동 수집·운반에 참여한다.
- 수행 가능한 작업이 없으면 대기한다.
- 기초 자원 획득 시설은 고정 배정 없이 이용하는 자동 수집 대상이다. 개체 없이 수집하지 않는다.
- 배양으로 합류한 보급형은 미배정 상태에서 자동 수집·운반에 참여한다. 출현 위치·시점은 [생산시설의 배양 완료](../01-production/facilities.md#cultivation)를 따른다.

전체 모델의 기능 분류가 모든 모델의 프로토타입 구현을 뜻하지는 않는다.

## 보급형의 시설 배정

D-052의 배정 규칙은 다음과 같다.

1. 플레이어가 보급형 개체를 골라 재료 가공시설 또는 공용 생명체 배양시설 한 곳에 직접 배정한다.
2. 한 개체는 동시에 한 시설만 담당한다.
3. 기초 자원 획득 시설과 범용 저장소는 고정 배정 대상에서 제외한다.
4. 배정 개체는 해당 시설의 생산 작업을 담당하며, 작업할 수 없을 때는 아래 자동 작업 규칙을 따른다.

배정 설정만으로 생산 속도가 100%가 되지 않는다. 실제 작업 여부에 따른 100%·20% 전환과 재료 공급은 [생산 공통 회차 규칙](../01-production/facilities.md#production-cycle)의 책임이다(D-058). 작업자 배정이 없어도 준비 가능한 한 회차분을 공급하며, 기존 예약·운반·도착 재료를 유지한다.

<a id="assignment-change"></a>

## 배정 변경·해제 시 행동 전환

배정 설정은 즉시 변경한다. 개체의 행동 전환은 다음과 같다(D-053).

| 현재 행동 | 처리 |
| --- | --- |
| 수집·가공·배양 작업 | 해당 개체의 작업을 중단한다. 진행도와 투입 상태는 시설에 보존하고 이미 소비한 재료를 다시 소비하지 않는다. 실제 작업자가 없어진 가공·배양시설은 저속 생산 조건을 적용한다. |
| 정상 운반 | 자원을 집기 전 이동도 포함하여 기존 운반을 완료한 뒤 새 배정 상태에 따라 행동한다. |
| 생산 작업을 위한 이동·대기 | 기존 행동을 취소하고 새 배정 상태에 따라 행동을 다시 선택한다. |

변경 후에는 새 담당 시설을, 해제 후에는 미배정 상태의 자동 수집·운반 규칙을 따른다. 중단 대상은 해당 개체의 작업이며, 같은 시설의 모든 작업자를 중단시키지 않는다. 수집 진행도도 시설에 보존하고 이미 완료된 자원은 완료품·운반 규칙을 유지한다.

배정 변경만으로 운반 작업·예약·보유 자원을 버리거나 초기화하지 않는다. 경로 차단·시설 변경은 [운반 예외 규칙](../02-logistics/storage-and-transport.md#transport-exceptions)을 적용한다.

<a id="unavailable-work"></a>

## 담당 시설에서 작업할 수 없을 때

재료 부족·배양 대상 미선택·완료품 입고 대기·담당 시설 접근 불가로 작업할 수 없으면 **배정을 유지한 채** 자동 수집·운반에 참여한다. 가능한 작업이 없으면 대기한다(D-055).

담당 작업이 가능해지면 해당 작업을 선택 후보에 다시 포함하고 기존 우선순위로 선택한다. 담당 작업에 무조건 우선권을 부여하지 않는다. 이미 재료를 소비한 진행 중 회차는 보존된 상태에서 작업 가능한지 판단하며, 재료를 다시 요구하거나 소비하지 않는다.

| 현재 행동 | 담당 작업이 가능해졌을 때 재선택 시점 |
| --- | --- |
| 정상 운반 | 자원을 집기 전 이동을 포함해 기존 운반을 완료한 뒤 |
| 실제 수집 | 현재 회차 자원 생성까지 완료한 뒤 |
| 운반에 속하지 않는 이동·대기 | 즉시 |

수집 개체는 생성한 자원의 저장소 입고를 기다리거나 직접 운반할 의무가 없다. 다만 획득시설은 완료품 전량이 실제 입고될 때까지 다음 회차를 시작하지 않는다.

이 절은 배정을 유지한 자동 전환에 적용한다. 플레이어가 배정을 변경·해제하면 위 D-053의 처리에 따라 수집도 중단한다. 경로 차단·시설 변경에는 물류 예외를 적용하며, 연구소 일시정지 중에는 다른 작업도 수행하지 않는다. 개체가 자동 작업 중일 때 시설 자체의 저속 생산은 생산시설의 가동 조건을 따른다.

## 개발 중 결정할 상세와 후속 범위

- **개발 중 결정(D-059):** 작업 우선순위 프리셋 값, 시설별 동시 인원, 구체적인 작업 처리와 조정 수치. 이를 사전 기획의 개별 승인 항목으로 늘리지 않는다.
- **후속 개발:** 고급형의 구체적인 강화 항목·정도와 특화형의 특수 기능.
- **미확정 기능:** 시작 프로토타입 모델의 추가 배양, 모델 간 업그레이드 기능을 현재 승인 범위로 추가하지 않는다.

건설 비용·시간·지급 방법은 [시설 배치](../03-space/placement.md)와 [프로토타입 범위](../../04-delivery/02-release/scope.md)를 따른다.

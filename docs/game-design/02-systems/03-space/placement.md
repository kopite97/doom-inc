## 범위와 공간 기준

이 문서는 건설, 시설의 배치·회전·이동, 고정 상호작용 위치와 배치 조작 중 시간 흐름의 정식 규칙을 관리한다. 자재 운반이 많아지면서 배치와 접근 동선의 중요성을 깨닫게 하는 것이 목표다(D-001·D-029).

프로토타입은 하나의 고정된 직사각형 건설 영역을 사용하며, 부지 확장과 층 추가는 제외한다(D-034). 정식 콘텐츠 목록과 시작 구성은 [프로토타입 범위](../../04-delivery/02-release/scope.md)를 따른다.

연구소의 공간 정보는 공통 Map에서 관리하며 배치 검사와 경로 탐색이 함께 참조한다(D-076). 구체적인 구조는 [Thing과 정의 데이터](../../05-development/01-architecture/thing-model.md)를 따른다.

## 건설과 시설 사용 시작

모든 보조형 모델은 건설할 수 있다. 생산시설 작업자로 배정하는 능력과 별개이므로 시작 프로토타입도 건설할 수 있다(D-057·D-060).

1. 플레이어가 건설할 시설과 위치를 지정한다.
2. 보조형이 자동으로 건설한다.
3. 필요한 자원과 건설 작업이 완료되면 시설을 사용할 수 있다.

시설 4종은 유기물로 건설한다(D-071). 첫 시설·초기 건설 자원과 생산 진입 흐름의 기준은 [프로토타입 범위](../../04-delivery/02-release/scope.md)다. 위치를 고르는 동안은 아래 일시정지 규칙을 적용하고 확정 후 연구소 진행을 재개한다.

## 격자와 배치 제약

D-028의 기본 제약은 다음과 같다.

- 정사각 격자에 칸 단위로 시설을 배치한다. 시설마다 점유하는 가로·세로 칸 수가 다를 수 있다.
- 플레이어는 건설 영역 안에서 위치를 자유롭게 선택한다.
- 시설끼리 겹치거나 시설이 건설 영역 밖으로 나가는 배치는 금지한다.
- **통로를 막는 배치는 허용**한다. 다만 접근할 수 없는 시설에서는 개체가 작업하거나 자원을 주고받지 못한다.
- 생산시설을 포함한 시설은 이동을 막으며, 생명체끼리는 겹쳐 지나갈 수 있다. 거리·경로 기준은 [물류의 이동 규칙](../02-logistics/storage-and-transport.md#transport-selection)을 따른다(D-018·D-027).
- 고정 상호작용 위치에 접근할 수 없으면 가공·배양의 저속 자동 생산도 멈추고 상태를 보존한다. 생산의 정식 조건은 [생산 공통 회차](../01-production/facilities.md#production-cycle)를 따른다(D-058).

<a id="interaction-position"></a>

## 고정 상호작용 위치와 회전

각 시설의 정면에 지정된 공용 위치에서만 자원 투입·생산물 회수·시설 작업을 수행한다(D-012·D-029). ‘작업 위치’와 ‘상호작용 위치’는 같은 의미다.

- 접근할 수 없다고 다른 면이나 임의의 위치로 대체하지 않는다.
- 시설은 90도 단위로 네 방향으로 회전한다. 직사각형 시설은 90도 회전할 때 가로·세로 점유 칸 수가 서로 바뀐다.
- 고정 상호작용 위치도 시설과 함께 회전하여 지정된 정면 위치를 유지한다.
- 회전 결과에도 중첩 금지·건설 영역 밖 배치 금지 제약을 적용한다. 통로 차단은 허용하며, 회전 후 접근할 수 없으면 상호작용과 저속 생산도 보존 대기한다(D-030·D-058).

공용 상호작용 위치가 여러 개체의 동시 작업을 승인하는 것은 아니다.

<a id="facility-movement"></a>

## 시설 이동과 상태 보존

이미 설치한 시설 이동에는 자원 비용·별도 이동 작업·대기시간이 없다. 새 위치를 **확정할 때 즉시 적용**하며, 확정 전에는 기존 위치를 유지하고 취소하면 그대로 둔다(D-031). 이 무료·즉시 이동 규칙을 새 건설 비용·시간에 확대하지 않는다.

새 위치에도 위 배치 제약을 적용하며 공간 정보를 갱신한다. 이동 시 상태는 다음과 같이 보존한다(D-032).

| 대상 | 처리 |
| --- | --- |
| 생산 중 시설 | 현재 회차 진행도와 투입 상태를 유지한다. 초기화하거나 자원을 다시 소비하지 않는다. |
| 시설에 남은 자원 완료품 | 해당 시설과 함께 이동한다. |
| 이미 운반 중인 자원 | 운반 개체가 계속 보유한다. |
| 저장소 | 자원 종류·수량과 허용 자원 설정을 유지한다. |
| 운반 작업·예약 | 변경된 작업 위치로 경로를 다시 계산한다. 기존 대상을 이용할 수 있으면 작업·유효 예약을 유지하고, 불가능하면 물류 예외를 적용한다. |

이동 후 상호작용 위치에 접근할 수 없으면 저속 생산을 포함해 생산을 멈추고 상태를 보존한다. 접근이 회복되면 이어간다. 자원 완료품 전량이 실제 저장소에 입고돼야 다음 생산을 시작하는 조건을 유지한다. 이는 여러 회차 재고를 허용하거나 배양 생명체를 저장소에 입고하는 규칙이 아니다.

경로 변경·부분 입고·목적지 재선택은 [운반 예외 규칙](../02-logistics/storage-and-transport.md#transport-exceptions)을 따른다.

## 배치 조작 중 연구소 일시정지

시설을 배치·이동·회전할 위치와 방향을 고르는 동안 연구소의 생산·수집·운반·생명체 이동을 일시정지한다(D-033).

- 일시정지 동안 진행 상태와 기존 작업·예약을 유지한다.
- 확정하면 배치 변경을 반영하고 경로 재계산·시설 변경 예외를 적용한 뒤 연구소 진행을 재개한다.
- 취소하면 기존 배치에서 그대로 재개한다.

이 규칙의 대상은 연구소 진행이다. 한 판의 종료와 외부 활동을 포함한 전체 진행 제어는 [GameFlow와 시스템 책임](../../05-development/01-architecture/game-flow.md)을 따른다.

## 개발 중 결정할 상세

D-059에 따라 건설 비용·시간, 초기 자원의 전달·작업 선택 구현, 시설 크기·상호작용 위치의 좌표·동시 작업 인원, 경로 알고리즘과 세부 클래스는 개발하면서 정한다. 건설 영역의 구체적인 칸 수는 시설 구성에 맞춰 결정한다. 승인된 배치·접근·상태 보존 규칙은 유지한다.

## 목표와 범위 원칙 (D-010·D-011·D-035)

1차 목표는 **충분히 반복 플레이 가능한 프로토타입 완성**이다. 생산·운반·배양·운영 지원과 방출·전과 보고·멸망 진행·병목 개선을 연결하되, 생명체·자원 등 에셋 종류는 필요한 최소 구성으로 제한한다.

핵심 게임 규칙을 임의로 만들지 않고 구현·검증할 수 있는 수준으로 1차 필수 기획을 마무리했다. 필수 1·2·3·4·6·7은 완료이며, 필수 5의 기본 규칙은 확정하고 초기값·조정 수치는 개발에 위임했다(D-059). 기획 완료는 실제 구현·검증 완료와 구분한다.

세밀한 최종 밸런스·정식 출시 콘텐츠·수익화를 모두 정해야 개발을 시작할 수 있는 것은 아니다. 특정 동시 개체 수 제한·플레이 시간·검증 반복 횟수를 추가로 확정하지 않는다.

## 최소 콘텐츠

### 자원 (D-036·D-071)

| 구분 | 가칭 | 역할 |
| --- | --- | --- |
| 기초 자원 1종 | 유기물 | 가공 원료이자 시설 4종의 건설 재료이며 획득·운반·보관 대상이다. |
| 가공 재료 1종 | 배양액 | 생명체 배양 재료이며 가공·운반·보관 대상이다. |

자원은 총 2종이며 이름은 가칭이다. 수집·가공·배양의 레시피와 회차 규칙은 [생산시설](../../02-systems/01-production/facilities.md), 수량 합산 저장 용량과 운반 규칙은 [저장과 운반](../../02-systems/02-logistics/storage-and-transport.md)에서 관리한다.

### 생명체 (D-038·D-056·D-057)

| 종류 | 프로토타입 역할 |
| --- | --- |
| 보조형 프로토타입 모델 1종 | 시작 개체. 건설·수집·운반이 가능하며 생산시설 작업 배정은 불가하다. |
| 보조형 보급형 1종 | 하위 모델의 기능과 생산시설 작업을 수행하며 배양 대상이다. |
| 침공형 1종 | 배양·외부 방출·전과 보고·멸망 진행에 연결된다. |

생명체는 총 3종이다. 모든 보조형은 건설할 수 있고, 상위 모델은 하위 모델의 기능을 수행한다. 모델명 ‘프로토타입’과 개발 단계의 프로토타입을 구분한다. 시작용 프로토타입 모델의 추가 배양은 포함하지 않는다. 모델별 기능·배정·작업 전환은 [보조형 모델](../../02-systems/05-creatures/support-models.md), 배양 규칙은 [생산시설](../../02-systems/01-production/facilities.md)을 따른다.

### 시설과 공간 (D-034·D-039·D-071)

| 시설 종류 | 역할 |
| --- | --- |
| 기초 자원 획득 시설 | 유기물을 얻는다. |
| 재료 가공시설 | 유기물을 배양액으로 가공한다. |
| 공용 생명체 배양시설 | 보급형과 침공형을 같은 종류의 시설에서 배양한다. |
| 범용 저장소 | 두 자원을 보관하고 허용 자원을 설정한다. |

시설은 총 4종이며 **모두 유기물로 건설**한다. 종류 수와 시작에 제공하는 시설 수는 구분한다. 생산은 [생산시설](../../02-systems/01-production/facilities.md), 저장은 [저장과 운반](../../02-systems/02-logistics/storage-and-transport.md)을 따른다.

하나의 고정된 직사각형 건설 영역을 사용한다. 구체적인 칸 수는 시설 구성을 바탕으로 개발에서 정한다. 건설·배치·회전·이동·연구소 일시정지의 정식 규칙은 [시설 배치](../../02-systems/03-space/placement.md)에서 관리한다.

## 시작 상태 (D-056·D-057·D-071)

| 항목 | 시작 상태 |
| --- | --- |
| 시설 | 선배치하지 않는다. 기초 자원 획득 시설과 범용 저장소를 건설하며 시작한다. 첫 생산시설은 기초 자원 획득 시설이다. |
| 보조형 | 프로토타입 모델 1개체, 보급형 0개체 |
| 침공형 | 0개체 |
| 초기 자원 | 기초 자원 획득 시설 1개와 범용 저장소 1개를 건설할 유기물 |
| 초기 개체 기능 | 건설·수집·운반. 생산시설 작업 배정은 없다. |
| 공용 배양시설 추가 시 | ‘선택 없음’ 상태이며, 대상을 고르기 전에는 재료 공급과 배양을 시작하지 않는다(D-051). |

초기 지급 자원은 저장소 건설 전에도 건설에 사용할 수 있어야 한다. 지급 위치·전달 방법·정확한 건설 비용·지급 수량·작업시간은 개발하면서 정한다. 필요한 자원과 건설 작업이 완료되어야 시설을 사용할 수 있다(D-060).

## 생산 사이클 진입 흐름 (D-071)

1. 시작 프로토타입이 지급된 유기물로 기초 자원 획득 시설과 범용 저장소를 건설한다.
2. 유기물을 수집하고 저장소에 입고하는 흐름을 반복한다.
3. 모은 유기물로 재료 가공시설을 건설하고 배양액을 생산·입고한다.
4. 유기물로 공용 생명체 배양시설을 건설하고, 선택한 생명체의 배양을 시작한다.

첫 보급형이 나오기 전에는 프로토타입이 건설·수집·운반을 맡고 가공·배양시설은 기존 20% 자동 생산으로 가동한다. 보급형을 배양한 뒤 배정하여 실제 작업 중 100% 속도로 개선할 수 있다(D-058). 위 흐름은 별도의 해금 조건이나 강제 배양 순서를 요구하지 않는다.

획득·가공 결과물의 전량 실제 입고, 저장소를 통한 재료 공급, 배양시설의 초기 선택과 반복 규칙을 유지한다. 세부 생산 조건과 승인된 레시피·시간은 [생산시설](../../02-systems/01-production/facilities.md)을 따른다. 개발 중 정할 비용·용량·건설 시간은 이 진입 흐름이 성립하도록 설정하고 검증한다.

## 프로토타입 완료 기준과 검증 (D-070)

다음 네 가지를 실제 플레이로 확인하면 완료로 판단한다. **현재는 기획 기준만 확정했으며 실제 구현·검증은 수행하지 않았다.**

| 기준 | 확인할 플레이 결과 |
| --- | --- |
| 전체 흐름 | 초기 건설에서 생산·운반·배양을 반복하고, 침공형 방출·지속적인 전과 보고·실제 활동 성과 누적을 거쳐 멸망 연출·결과 화면·다시 시작까지 이어진다. 보고 표시·열람 여부와 관계없이 성과가 반영된다. |
| 병목 개선 | 작업 상태와 대기 이유로 대표적인 병목을 찾고, 배치·배정·저장 설정 등을 조정하여 흐름을 개선할 수 있다. |
| 저장·복원 | 자동 저장과 마지막 저장 상태 이어하기가 작동하며, 게임이 꺼진 동안에는 진행하지 않고 ‘다시 시작’으로 저장이 초기 상태가 된다. |
| 모바일 검증 | 실제 Android 기기 한 종류에서 인터넷 없이 혼자 플레이하며 가로·세로 모두의 표시와 터치 조작을 확인한다(D-089·D-090). 진행을 막는 오류나 심각한 성능 문제가 없어야 한다. |

개발 중 PC에서 반복 검증하고 완료 전 실제 Android 기기에서 확인한다. 구체적인 반복 횟수와 성능 수치는 개발하면서 정한다. 모든 배치·운영 조합을 별도 완료 조건으로 확대하지 않는다.

현재 환경·저장의 정식 규칙은 [플레이 환경](../01-platform/environment.md), 화면과 양방향 지원은 [화면과 조작](../../03-player-experience/03-interface/controls.md), 선행 기반과 단계별 구현·검증은 [구현 계획](../../05-development/02-implementation/roadmap.md)을 따른다.

## 후속 개발 범위

| 대상 | 프로토타입에서의 경계 |
| --- | --- |
| 보조형 고급형·특화형 | 후속 개발. 특화형의 특수 기능은 미정이다. |
| 부지 확장·층 추가 | 제외한다. 고정 직사각형 건설 영역을 사용한다(D-034). |
| 여러 세계 진행·환생·영구 보너스 | 후속 개발. 프로토타입은 1개 세계로 검증한다(D-064·D-065). |
| 침공형 귀환·수명·전투 손실 | 후속 개발. 방출한 침공형은 세계 멸망까지 활동하며 성과를 쌓는다(D-066). |
| Apple(iOS/App Store)·ONE store 배포 | 후속 계획. 프로토타입은 Android 개발·검증이며 배포 일정·순서·절차는 미정이다(D-089). |
| 수익화·정식 출시 콘텐츠 | 필수 완료 조건이 아니다. [수익 모델](../03-business/model.md)의 확인 범위를 유지한다. |

전체 게임은 다양한 콘셉트의 세계를 차례로 파괴하는 방향이다. 판타지·SF는 가능한 예시이며 확정된 세계 목록은 아니다. 프로토타입의 목표 도달·멸망 연출·결과·다시 시작 규칙은 [목표와 반복 흐름](../../01-direction/02-experience/core-loop.md)에서 관리한다.

콜로니 시뮬레이션 장르, 평시 참여 방침 설정과 직접 전투 조작 없는 자동 전투는 확정 사항이다. 미정 질문에 다시 포함하지 않는다.
성장 기획은 다양한 요소를 추가 논의하는 초안이며, 현재 예시만으로 전체 구조를 확정하지 않는다.

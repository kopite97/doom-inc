# 배양실 전문화

- 갱신일: 2026-11-17
- 상태: 배양 촉진기·원료 순환기와 배양 방식 선택 확정. 형질 유도기는 후반 확장 후보이며 수치·실내 및 장비 손상 처리는 미정
- 근거: 사용자가 두 지원 장비의 채택, 형질 유도기의 후보 유지, 수치 및 손상 처리 유보를 요청.

## 목적과 기본 배양

- 배양 대상을 고르는 것에 더해 시간과 원료 사정에 맞는 배양 방식을 선택한다. 긴급 보충과 장기 증식을 서로 다른 운영 선택으로 만든다.
- 기본 배양은 실외에서도 가능하며 시설 설치에는 [바닥](construction.md#바닥과-설치-기반)이 필요하다. 전문 배양은 완성된 [실내](rooms.md)의 지원 장비를 활용한다.
- 필요한 재료를 전량 공급한 뒤 시작 시 소비하고 자동 진행하는 [생산 규칙](production.md)을 유지한다. 전문화 때문에 생명체의 상주 제조 작업을 추가하지 않는다.

## 채택한 지원 장비

장비 명칭은 역할을 설명하는 임시 명칭이며 구체적인 수치는 미정이다.

| 장비·방식 | 효과 | 대가와 용도 |
| --- | --- | --- |
| 기본 배양 | 기준 원료와 시간으로 배양 | 별도 지원 장비 없이 운영 |
| 배양 촉진기·촉진 배양 | 배양 시간 감소 | 시작 생체 원료 비용 증가. 긴급 보충·빠른 확장 |
| 원료 순환기·순환 배양 | 시작 생체 원료 비용 감소 | 배양 시간 증가. 장기 증식·원료 절약 |

- 원료 순환은 완료 후 원료를 반환하는 방식이 아니라 시작 비용을 낮추는 방식으로 적용한다.
- 장비는 같은 실내의 배양시설을 지원하며 장비별 지원 가능한 시설 수를 제한한다. 지원 수·연결 대상 선택의 상세 방식은 미정이다.
- 한 배양 회차에는 한 가지 방식만 적용한다. 촉진과 순환의 효과를 같은 회차에 중첩하지 않는다. 같은 종류 장비 여러 개의 지원 관계와 중복 효과 처리는 추가 기획한다.

## 플레이어 설정과 회차

- 배양시설에 기본·촉진·순환 방침을 설정하면 다음 배양부터 계속 적용한다. 회차마다 반복 선택하는 것을 필수로 하지 않는다.
- 방침 변경은 다음 회차부터 적용하며 진행 중 회차의 선택을 임의로 바꾸지 않는다.
- 시작 전에 적용 방식·실제 필요 원료·예상 배양 시간을 보여준다. 원료 배분은 [물류 정책](logistics.md)을 따른다.
- 이 설정은 배양 방식의 유지이며 목표 개체 수 자동 유지의 채택을 뜻하지 않는다.
- 실내 조건 상실·지원 장비 손상이나 제거 시 신규 및 진행 중 배양을 어떻게 처리할지는 미정이다. 기본 속도 전환·비용 유지·중단·환불·자동 대체를 임의로 확정하지 않는다.

## 후반 확장 후보: 형질 유도기

- 배양 환경에 따라 태어난 개체의 작업 수행 수치에 차이를 주는 장비를 검토한다. 현재 채택한 필수 구현 범위가 아니다.
- 운반량 증가와 이동 속도 감소, 건설 속도 증가와 유지 소비 증가 같은 교환은 설명용 예시다. 실제 효과·지속성·개체별 차이·표현 범위는 미정이다.
- 도입한다면 기존 가능한 행동은 유지하고 관련 수치로 차이를 표현하는 [생명체 원칙](creatures.md#작업-특화)을 따른다. 별도 특화 여부·종류 필드를 추가하는 근거로 삼지 않는다.

## 미정

- 장비의 정식 이름·크기·비용·해금, 원료와 시간의 변화량, 지원 시설 수 등 구체적인 수치.
- 지원 대상의 연결·해제·범위와 복수 장비의 관계, 방침에 필요한 장비가 없거나 지원 한도가 찼을 때의 대기·안내.
- 실내·장비 손상 및 제거, 방 분할·병합으로 지원 조건이 변할 때 신규·진행 중 회차의 비용·시간·진행도·복구 처리.
- 방침 변경 시 이미 공급·예약된 다음 회차 원료의 정리, 취소·시설 이전 시 재료와 진행도 처리.
- 형질 유도기의 도입 여부·효과와 개체별 능력 비교·기록 범위.

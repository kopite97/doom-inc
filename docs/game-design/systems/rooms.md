# 벽·문·지붕과 실내 판정

- 갱신일: 2026-11-25
- 상태: 구조물 건설·방과 실내 구분·자동 지붕 작업 확정. 첫 프로토타입의 모든 시설에 실내 배치 원칙을 적용한다. 시설별 실외 성능과 수치는 세부 기획 대상이다.
- 근거: 사용자가 제안한 구조물 건설과 방·실내 판정을 채택하고, 수치 및 지붕 지지·붕괴는 미정으로 유지하며 시설별 효과는 추가 논의하도록 요청.

## 건설

- 벽·문·지붕은 [건설 가능한 생명체](creatures.md)가 직접 짓는다. 예약·자재 공급·현장 작업·완공은 [건설](construction.md)의 공통 흐름을 따른다. 자재 필요량과 지붕 자재 소모 여부 등 구체 비용은 미정이다.
- 벽은 드래그로 여러 칸을 예약하고 생명체가 작업을 나누어 진행할 수 있게 한다. 문도 건설 작업으로 설치한다.
- 설계도나 미완성 구조물만으로 방의 경계를 인정하지 않는다. 완공된 구조를 기준으로 판정한다.
- 벽 건설로 안쪽 작업이나 출입 경로가 막히는 상황을 고려한다. 건설 순서·경고·접근 불가 처리의 상세 방식은 미정이다.

## 방과 실내

방의 경계와 지붕 완성 여부를 구분한다. RimWorld의 구획·지붕 구분을 참고하되 아래 규칙을 우리 게임의 기준으로 사용한다.

| 공간 상태 | 판정 |
| --- | --- |
| 외부로 이어지는 열린 공간 | 실외 |
| 완공된 벽·문으로 둘러싸였지만 지붕이 미완성인 공간 | 방이지만 실내는 미완성 |
| 완공된 벽·문으로 둘러싸이고 지붕도 완성된 공간 | 실내 |
| 지붕은 있지만 외부로 열린 공간 | 지붕이 있는 실외 |

- 문은 개체가 통과하면서 잠깐 열려도 방의 경계로 유지한다. 문 개폐마다 방을 제거하거나 다시 만들지 않는다.
- 벽이나 문을 철거하거나 구멍이 생겨 공간이 연결되면 구획을 다시 판정한다. 외부와 연결되면 실내 조건을 충족하지 않는다. 내부 칸막이 제거는 연결된 전체 공간의 경계·지붕으로 판정한다.
- 벽·문·지붕의 전투 피해·파괴 방식은 [전투](defense.md)의 추가 기획 대상이다. 구획 변경 규칙을 근거로 구체적인 파괴 공격이나 붕괴 피해를 자동 추가하지 않는다.
- 부분 지붕은 완성된 실내로 취급하지 않는다. 시설이 여러 공간에 걸친 경우의 적용 기준과 자연 지형의 경계 인정 범위는 미정이다.
- 2026-11-17 채택한 [바닥 시공](construction.md#바닥과-설치-기반)은 시설 설치 조건이며 방·실내 판정 조건은 아니다. 바닥만 있는 공간은 실외이고, 경계와 지붕이 완성된 실내에 자연 지면이 남아 있어도 방은 유지된다.

### 병원 판정과 구조 대기

프로토타입에서는 실내 판정을 받은 방 안에 완공된 기본 회복시설이 한 대 이상 있으면 그 방을 자동으로 병원으로 판정한다. 병원으로 판정된 방은 기본 회복시설이 가득 찼을 때 쓰러진 생명체가 구조 후 대기할 수 있는 장소다. 본편의 세부 판정 조건은 추후 정한다.

## 지붕 작업

- 완공된 벽·문이 공간을 둘러싸면 해당 방의 지붕 건설 작업을 자동 요청한다. 건설 가능한 생명체의 작업 후 지붕이 완성된다. 방 판정만으로 지붕이 즉시 생기지 않는다.
- 플레이어는 지붕을 만들지 않을 공간을 지정할 수 있다. 자동 지붕 요청은 이 설정을 따른다.
- 지붕의 자재·작업량·건설 범위 수치, 기둥·지지 거리·지지 조건·붕괴 도입 여부와 피해는 미정이다. 다른 게임의 수치나 붕괴 규칙을 기본값으로 적용하지 않는다.

## 관찰

- 기본 화면에서는 지붕을 숨겨 내부 생명체의 활동을 볼 수 있게 한다. 구조물과 지붕의 건설 진행은 확인 가능하게 한다.
- 공간 선택 시 실내·지붕 미완성·외부 연결 등 상태와 이유를 구분해 보여준다. 정확한 문구와 표시 방식은 미정이다.

## 시설 효과와 추가 논의

2026-11-25 사용자 지정으로 첫 프로토타입의 모든 시설은 실외에서도 기본 기능을 수행하고, 완성된 실내에서 온전한 효과를 낸다. 첫 건설 자재 가공대와 창고에도 적용한다. 첫 가공대는 실외에서 건설 부품을 더 느리게 만든다. 그 밖에 시설마다 실내 배치로 어떤 효과가 얼마나 달라지는지는 개발 단계에서 논의한다.

- 2026-11-17 채택한 배양 촉진기·원료 순환기의 효과와 같은 실내 지원 조건은 [배양실 전문화](cultivation.md)를 따른다. 형질 유도기는 후반 후보이며 수치·손상 처리는 미정이다.
- 2026-11-17 채택한 계통별 분석 장비는 [연구시설 전문화](research.md#연구시설의-실내-전문화)를 따른다. 조수의 직접 연구만 강화하고 활동 보너스는 증폭하지 않으며 수치·연결 변경·손상 처리는 미정이다.
- 2026-11-17 채택한 원료 회수·일괄 혼합 장비는 [시약 제조 전문화](production.md#시약-제조시설의-실내-전문화)를 따른다. 생명체의 제조 작업은 유지하며 수치·장비 손상 처리는 미정이다.
- 2026-11-17 채택한 [회복시설 전문화](maintenance-and-loss.md#회복시설의-실내-전문화)는 재생 촉진 장치로 회복을 가속하고 수용량은 시설 증설로 확보한다. 가속 원료 부족 시 기본 회복을 이어가며 수치·손상 처리는 미정이다.
- 창고의 실외 사용과 저장·공급·보충 역할은 [창고](logistics.md#창고)를 따른다.
- 생존 중심의 환경 페널티를 그대로 도입하지 않고 연구소 운영과 성장 목적에 맞는 효과를 추가 논의한다. 현재 초안에 신규 효율 수치·시설 가동 제한·온도·청결·오염 규칙을 추가하지 않는다.
- 시설별 전문화와 장비 효과는 각 담당 문서를 따른다. 작업 도중 실내 상태가 바뀔 때의 세부 처리는 개발 단계에서 정한다.

## 미정

- 구조물 비용·작업량·크기·동시 작업 인원, 지붕 지지와 붕괴 관련 전체 규칙.
- 모서리·대각선·맵 경계·자연 암벽의 구획 기준, 계속 열린 문과 특수 출입구, 여러 공간에 걸친 시설의 판정.
- 지붕 제외 구역 변경·철거·방 병합 및 분할 이후 남은 지붕과 작업 요청의 처리.
- 건설 접근·출입 확보, 철거·파괴 후 복구와 통행의 세부 처리.
- 채택한 시설별 전문화의 세부 적용·연결·손상 처리, 방의 기능 구분·혼합 사용.

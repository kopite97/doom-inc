# 생명체와 코스트

- 갱신일: 2026-11-17
- 상태: 개체 중심 설계·히든 코스트·수치 기반 작업 특화·초기 3종 확정. 유지·손실의 채택 방향은 별도 문서에서 관리하며 이름·수치는 미정
- 근거: 개체 중심 설계·수치 기반 특화·기존 3종 재활용 지시와 2026-11-17 초기 3종 모두 전투 후 구조 가능하도록 지정. 이름·수치는 미정으로 유지.

## 목적과 확정 규칙

- 생명체를 보조형·침공형·특수형으로 고정 분류하지 않고, 생명체별로 할 수 있는 일을 정의한다.
- 2026-11-17 지시에 따라 운반과 공격이 가능한 개체, 공격만 가능한 개체처럼 필요한 행동을 조합한다. 구체적인 기능 분할은 이후 공통 경계 설계에서 정하며 게임 기획은 가능한 행동과 전환 규칙을 관리한다.
- 외부 침공에는 종류와 관계없이 공격 행동이 가능한 개체만 출격할 수 있다. 출격의 다른 조건은 [침공 구상](external-world.md)을 따른다. 공격 가능 여부와 [본진 전투 참여 방침](defense.md#평시-방침과-전투-모드)은 구분한다.
- 기본 행동은 자율적이며 플레이어가 운영에 개입할 수 있다. 작업 선택은 [자율 행동](work.md)을 따른다.
- 커맨더는 지휘 기능을 가진 생명체다. 전체 생명체를 새로운 배타적 타입 체계로 나누는 규칙이 아니다.
- 생명체에 내부 서열을 정하는 히든 스탯인 코스트를 둔다. 초기 커맨더의 배분 기준으로 사용한다.
- 코스트는 JSON 데이터로 관리해 밸런싱한다. 배분 수준의 의미는 [커맨더](commanders.md)가 담당한다.
- 가능한 일과 현재 행동을 이해할 수 있고 배경설명도 읽을 수 있어야 한다. [표현 기준](../experience/interface.md)을 따른다.

## 작업 특화

- 어떤 작업을 수행할 수 있는지와 얼마나 잘 수행하는지는 구분한다.
- 특정 작업에 대한 특화는 해당 작업의 수행 수치 차이로 표현한다. 별도의 특화 여부·특화 종류 필드를 추가해 판정하지 않는다.
- 건설도 생명체별 가능한 행동이며, 초반에 만들 수 있는 개체 중 건설 가능한 생명체가 있다. 이후 건설에 더 높은 성능을 보이는 생명체를 만들 수 있다. 흐름은 [건설](construction.md)을 따른다.
- 건설 속도 차이는 수치 기반 특화의 예시다. 특화만을 이유로 별도의 건축가 타입·전용 시설 건설 권한·새 행동을 자동 추가하지 않는다.
- 히든 코스트는 초기 배분의 서열 기준이며 실제 작업별 성능과 동일하지 않다. 특화 수치를 도입했다고 초기 커맨더의 코스트 기준을 자동 변경하지 않는다.

## 초기 생명체 3종

기존 생명체 3종을 재활용한다. 아래 색상·옛 이름은 재활용 대상을 식별하기 위한 표현이며 새 정식 이름이나 보조형·침공형 분류를 뜻하지 않는다.

| 재활용 대상 | 초기 운영에서 가능한 행동 | 역할과 성능 방향 |
| --- | --- | --- |
| 민트색 개체 — 기존 프로토타입 | 자원 수집·운반·건설·구조 | 초기 연구소의 수집·건설·운반을 맡는 기본 개체 |
| 보라색 개체 — 기존 보급형 | 시약 제조·운반·구조 | 시약 생산과 연구 재료 공급을 담당하며 제조할 일이 없으면 운반에 참여 가능 |
| 주머니 개체 — 기존 약탈형 | 자원 수집·운반·구조 | 운반량을 중심으로 기본 개체와 차이를 두어 물류 확대에 활용 |

- 위 목록은 초기 운영 행동의 구성이다. 보라색 개체에 건설·수집을 자동 부여하거나 주머니 개체에 제조·건설을 자동 부여하지 않는다.
- 유지·손실과 전투 종료 후 자동 구조는 [유지와 손실](maintenance-and-loss.md)을 따른다. 초기 3종의 구조 가능 여부는 확정이며, 개별 전투 행동과 구조·회복 세부 규칙은 추가 논의한다.
- 2026-11-17 수정한 [시작 흐름](../experience/early-game.md)에 따라 민트색 개체는 시작부터 제공한다. 플레이어가 배양시설을 건설한 뒤 추가 개체를 배양하며 초기 3종은 이른 시점부터 배양 가능하게 한다. 추가 배양 대상은 플레이어가 선택한다.
- 정식 이름과 모든 구체 수치, 배양 비용·시간·정확한 해금 조건은 미정이다. 기존 데이터의 수치를 새 밸런스로 확정하지 않는다.
- 상위 모델이 하위 모델의 모든 행동을 상속하던 옛 규칙을 승계하지 않는다. 이후 건설 특화 개체도 실제 작업 수치로 차이를 표현한다.
- 초기 3종은 전체 생명체 목록의 상한이 아니다. 기존 일반 침공형의 추가 재활용과 새 생명체 도입은 별도 논의한다.
- 원료 운반과 시약 제조는 [생산시설](production.md)에 연결한다. 배양은 재료 공급 후 자동 진행하고 연구는 조수가 담당한다.

## 제안과 미정

- 같은 종의 코스트를 공유할지, 개체별로 다르거나 성장하면서 변할지는 미정이다.
- 코스트와 실제 작업 속도·운반량·배양 비용·전투 능력의 관계는 미정이다. 높은 코스트를 모든 작업에 높은 능력으로 해석하지 않는다.
- 이름·성격·성장·활동 기록 등 같은 종 안의 개체성 구현 범위는 미정이다.
- 점액체의 분해·침투, 거구의 대량 운반·방벽 파괴, 전기 생명체의 장치 가동은 능력 활용 예시이며 확정 콘텐츠가 아니다.
- 초기 3종의 정식 이름·능력 수치·배양 조건의 세부 사항, 이후 생명체 목록과 개체 수 상한은 아직 정하지 않았다. 시작 구성의 채택 방향은 [초반 흐름](../experience/early-game.md)을 따른다.
- 유지 수치와 부상·활동 불능·회복·구조·영구 사망·재확보의 상세 규칙은 [유지와 손실](maintenance-and-loss.md)에서 논의한다.

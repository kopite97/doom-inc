# 커맨더의 지휘와 명령

- 갱신일: 2026-11-23
- 상태: 주인공 방침을 보조하는 인력 배분·단계별 판단·명령 흐름 확정. 명령 수준별 작업 배분 기준은 추후 결정
- 근거: 기존 커맨더 방향에 이어 2026-11-17 사용자가 주인공은 방침을 정하고 커맨더는 그 안에서 인력을 배분하는 철저한 보조 역할로 지정. 기존 명령 흐름 유지 요청.

## 목적과 확정 방향

- 커맨더는 주인공을 철저히 보조하는 생명체다. 플레이어가 [주인공](../experience/characters.md)을 통해 정한 행동 방침 안에서 반복적인 작업 우선순위·인력 배분 판단을 대신한다.
- 연구소 상태를 판단한 뒤 위임받은 범위의 작업 우선순위·배정을 조정한다. 독립적인 상위 방침을 만들거나 주인공의 결정을 덮어쓰지 않는다.
- 같은 지휘 기능을 가진 커맨더라도 판단의 수준과 고려하는 정보에 차이를 둔다.
- 초기 해금 커맨더는 단순한 작업 분배로 유휴 개체를 줄인다. 이후 커맨더는 실제 작업 속도와 자원 상황 등 더 많은 정보를 고려한다.
- 플레이어는 커맨더에게 특정 작업을 우선하도록 일괄 명령을 내릴 수 있다.
- 개체 수가 늘어날수록 커맨더의 존재가 운영에 중요해지도록 한다. 개별 생명체는 기본 작업을 자율 수행하고, 커맨더는 연구소 전체의 필요에 맞춰 배분을 조정한다.
- 커맨더의 가치를 만들기 위해 기본 생명체를 과도하게 비효율적으로 만들지 않는다. 규모 증가에 따른 조율 부담을 줄이는 데 초점을 둔다.
- [작업 선택](work.md)의 기본 판단을 토대로 자동 배분을 맡긴 개체를 조율한다. 플레이어가 고정한 개별 설정을 임의로 바꾸지 않는다. 긴급 작업과 고정 설정의 세부 충돌은 공통 규칙으로 추가 기획하며 커맨더의 독자적인 예외로 처리하지 않는다.
- 커맨더가 없어도 주인공의 방침 설정과 생명체의 기본 자율 행동은 작동한다. 커맨더의 유무로 명령 권한을 제한하지 않는다.
- 전투 참여·작업 유지 방침을 준수하고, 작업 유지 개체의 위협 시 대피를 작업 배정으로 취소하지 않는다. 전투로 작업 인력이 줄면 남은 위임 인력 안에서 배분을 조정한다. 커맨더 자신의 전투 행동은 별도 기획한다.

## 확정한 상호작용 흐름

1. 커맨더 생명체를 선택한다.
2. 선택한 생명체 옆에 명령 버튼이 활성화된다.
3. 명령 버튼을 누르고 작업 종류를 선택한다. 현재 논의한 작업은 운반이다.
4. 해당 작업의 수준 선택 화면에서 Low / Medium / High 중 수준을 선택한다.
5. 명령을 설정하고 커맨더가 그 방침으로 배분을 판단한다.

이 흐름은 주인공 명령 도입 후에도 유지한다. 주인공은 방침·개별 설정·자동 배분 위임을, 커맨더 화면은 위임 범위의 배분 설정을 담당한다. 하나의 명령을 완료하기 위해 두 캐릭터를 차례로 클릭하도록 요구하지 않는다.
화면의 상세 표현은 [UI](../experience/interface.md)를 따른다. 미정 수준의 의미를 개발자가 임의로 확정하지 않는다.

## 명령 수준

| 수준 | 현재 결정 |
| --- | --- |
| Low | 작업 배분 기준은 추후 결정한다. |
| Medium | 미정. 기존 작업에 미치는 영향을 고려하는 배분은 제안이다. |
| High | 미정. 필요하면 다른 작업에서 재배치하는 방식은 제안이다. |

- 커맨더의 알고리즘 수준과 명령 수준은 별개다. High 선택이 커맨더의 지능을 올리는 규칙은 아니다.
- 작업 긴급도는 명령 수준과 별도로 판단한다.

## 제안과 미정

- 생산·소비 속도를 예측하는 고급 커맨더는 확장 제안이다. 확정한 상위 방향은 실제 작업 속도·자원을 고려하는 배분까지다.
- 커맨더가 한 기만 존재할지 여러 기를 허용할지, 위계·지휘 체계를 둘지는 미정이다. 해금 조건·시점, 연구소 전체 또는 구역별 담당 범위와 여러 커맨더의 충돌 해결도 별도로 정한다.
- 동시 명령 수, 지속·해제·교체, 대상 인원 계산, 자동 배분 위임·해제와 수동 설정 보호의 세부 범위, 커맨더 부재 시 처리는 미정이다.
- 운반 외 운영 명령 목록은 미정이다. [완전 자동 전투](defense.md)의 확정 규칙에 따라 플레이어가 전투를 제어하는 지휘 명령은 제공하지 않는다.
- 현재 방침·판단 이유·최근 변경을 보여주는 UI, 해제 시 기본 행동 복귀는 제안이다.

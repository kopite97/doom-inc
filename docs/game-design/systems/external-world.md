# 외부 세력과 침공 구상

- 갱신일: 2026-11-26
- 상태: 침공·파괴하는 입장과 대체로 적대적인 외부 세력 방향 채택. 외부 세력의 생활·이해관계와 토벌군의 지역 방어 관점 확정. 외부 침공은 장기 도입 방향이며 추후 상세 기획할 구상
- 근거: 외부 세력·토벌군·침공 방향과 상세 기획 유보, 2026-11-17 본거지를 유지하며 침공 활동으로 자원을 확보하는 방향 지정.
- 2026-11-18 사용자가 침공 중 지역 고유 자원의 본거지 전송을 채택하고 개체 능력으로 새로 구현하도록 지정함.

- 2026-11-26 사용자가 외부 세력은 각자의 생활과 이해관계를 가지며 재앙 연구소를 일상을 위협하는 침공 거점으로 보고, 토벌군은 자기 지역을 지키려는 입장으로 묘사하도록 지정함.

## 외부 세력

- 플레이어는 외부 세계를 침공하고 파괴하는 입장이다. 외부 세력은 대체로 플레이어에게 적대적이다.
- 외부 세력의 적대 설정을 지원하는 방향으로 기획한다. 모든 세력이 예외 없이 영구 적대하거나 플레이어가 적대 여부를 직접 편집한다는 뜻은 아니다.
- 플레이어의 활동과 이전 결과가 이후의 경계·대응 등에 이어지는 지속적인 관계를 지향한다. 우호·교역이 관계의 필수 형태는 아니다.
- 먼저 각 세력과 플레이어의 관계·반응에 집중한다. 세력끼리의 외교·전쟁·동적 관계 시뮬레이션은 도입 여부를 별도 검토하며 현재 필수 범위로 잡지 않는다.
- 연구소를 공격해 오는 적 집단은 임시로 **토벌군**이라 부른다. 실제 습격 규칙은 [방어 전투](defense.md)를 따른다.
- RimWorld는 외부 세력·사건의 참고 대상이며, 우리 게임의 입장과 선택한 규칙에 맞춰 검토한다.

## 외부 세력의 관점과 토벌군의 동기

2026-11-26 확정.

- **외부 세력은 각자의 생활과 이해관계를 가진다.**
- **재앙 연구소를 자신들의 일상을 위협하는 침공 거점으로 본다.**
- **토벌군은 자기 지역을 지키려는 입장으로 묘사한다.**

이 기준은 세계관과 콘텐츠의 묘사 방향이다. 세력별 구체 생활상·이해관계·대사는 후속 기획한다. [시나리오와 첫 토벌군](events.md#시나리오와-첫-토벌군)의 발생 조건과 [방어 전투](defense.md) 규칙은 해당 원본을 따른다. 생활상을 묘사한다는 합의만으로 외부 주민의 생활 시뮬레이션이나 새 외교 기능을 추가하지 않는다.

## 플레이 결과와 외부 반응

- 외부 활동의 성과가 연구소의 성장이나 외부 상태 변화로 남아야 한다. 활동할 때마다 위협만 증가하는 보상 구조는 피한다.
- 특정 거점 파괴 후 일시적인 압박 감소, 새로운 연구 기회, 적의 경계·대응 변화는 제안이다. 구체적인 거점·보상·위협도 시스템은 미확정이다.
- 외부 상황은 [연구 선택](research.md)의 판단 재료가 될 수 있다. 정보의 제공 방식은 추가 설계한다.

## 외부 침공 구상

- 플레이어는 초반부터 외부 지역을 침공할 수 있다. 출격 가능한 생명체를 언제 어디로 보낼지는 플레이어가 정한다.
- 결과 보고만 받는 것에서 나아가 외부에서 벌어지는 전투 시뮬레이션을 관찰하는 경험을 지향한다.
- 기존의 플레이어 직접 제어 없는 자동 전투 방향을 이어간다. 수동 전투 조작을 추가하는 근거로 삼지 않는다.
- 출격 준비 → 자동 전투 관찰 → 결과·귀환 → 연구소 변화는 검토할 흐름이다. 2026-11-17 지시에 따라 종류와 관계없이 공격 행동이 가능한 개체만 출격할 수 있으며, 일부는 본진 방어를 위해 남겨두는 선택을 지원한다. 구체적인 편성·인원·준비·귀환과 기타 출격 조건은 미정이다.
- 외부 침공의 상세 규칙을 현재 연구·방어·사건 시스템의 필수 선행 조건으로 두지 않는다.
- 침공 중 생명체는 해당 지역에서만 얻을 수 있는 자원을 본거지로 전송할 수 있다. 기존 ‘약탈형’ 분류는 사용하지 않으며, 전송은 [생명체](creatures.md)의 능력으로 새로 구현한다.
- 침공 전에는 관심 있는 지역을 정찰해 현지 자원과 적에 관한 정보 일부를 확인할 수 있다. 플레이어는 이를 바탕으로 목표 지역과 출격 개체, 본거지 방어에 남길 개체를 고른다.
- 침공 중 [표본](resources.md#목적과-확정-방향)을 발견하면 어떤 생명체의 배양이나 시설 건설에 쓰이는지 확인하고 회수할 수 있다.
- 정예 생명체를 잃거나 원정이 실패해 입은 손실은 플레이어가 감수하고 이후 운영으로 극복한다.

## 미정

- 세력 수·특징·적대 설정 방식, 예외적 관계와 플레이어 행동에 따른 반응 규칙.
- 세력 간 관계 시뮬레이션의 도입 여부·범위. 고정 관계 설정과 동적 계산은 구분한다.
- 외부 지도·정보 공개·목표 선택, 토벌군과 외부 거점·세력의 관계.
- 정찰 방법과 공개할 정보의 범위, 표본의 종류·발견 및 회수 조건·배양에 쓰는 방식.
- 초반 출격의 구체적인 조건, 침공 목표·편성·전장·승패·보상·귀환 규칙.
- 전송 능력을 가질 개체와 세부 전송 조건, 지역 고유 자원의 종류·양·반복 공급 가능성. 연구를 통한 공급과의 관계는 [자원](resources.md)과 함께 정한다.
- 침공 중 본진 시간 진행·동시 운영 여부, 여러 장소의 관찰·알림·사건 처리.
- 첫 침공 범위와 출시 포함 범위·개발 순서.

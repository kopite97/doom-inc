# 마스코트와 조수

- 갱신일: 2026-11-26
- 상태: 주인공 선택을 통한 운용 방침 설정·역할 분리·초반 조수 선택·전문성 확정. 상세 명령 범위·인물·능력 미정
- 근거: 2026-11-17 주인공 클릭을 통한 명령·평시 전투 방침 지정으로 기존 상호작용 불가 규칙을 대체하고, 주인공의 방침 결정과 커맨더의 보조적 인력 배분 관계를 확정함.
- 2026-11-20 사용자가 건설 개체를 잃었을 때 조수의 휴대용 배양으로 재건하고, 가동 가능한 배양시설이 있으면 시설 배양을 선호하도록 지정함.
- 2026-11-20 사용자가 주인공의 즉시 게임오버 조건과 조수의 전투 후 구조·돌봄 방식을 확정함.
- 2026-11-20 사용자가 두 캐릭터의 습격 예고 대응과 습격 종료까지 유지되는 조수 대피 지시를 확정함.

## 마스코트

- 플레이어가 자신을 대입하는 인간 주인공이다.
- 맵을 자율적으로 돌아다니고 가끔 대사로 상황에 반응한다.
- 플레이어는 주인공을 클릭해 생명체의 행동 방침을 설정하는 [운용 방침](interface.md#작업-우선순위-설정) 화면으로 진입한다.
- 주인공의 자율 이동·상황 반응은 유지한다. 주인공 선택을 통한 방침 설정은 주인공 자체의 이동·공격을 직접 조작하는 기능을 뜻하지 않는다.
- 평시 전투 참여·작업 유지 설정은 [방어 전투](../systems/defense.md#평시-방침과-전투-모드)를 따른다. 세부 화면과 다른 운영 명령의 포함 범위는 추가 기획한다.
- 주인공을 통해 행동 방침·[작업 우선순위](../systems/work.md#기본-설정과-플레이어-개입)·담당 시설·자동 배분을 맡길 대상을 정한다. [커맨더](../systems/commanders.md)는 이 방침 안에서 인력을 배분하는 보조 역할이며 주인공의 결정을 임의로 변경하지 않는다.
- 커맨더가 없어도 주인공 명령과 기본 자율 행동은 작동한다. 기존 커맨더 선택 명령은 위임한 인력의 배분 설정으로 유지한다.
- 이전 기획에서 유지하기로 한 역할은 위와 같다. 언급하지 않은 옛 세부 규칙까지 자동 승계하지 않는다.

## 조수

- 조수는 주인공과 같은 인간으로 연구를 수행한다. 플레이어가 [시작 준비 화면](early-game.md)에서 선택한 조수는 처음부터 주인공과 함께한다. 플레이어가 첫 배양을 지시하면 조수가 중앙 터 근처에서 한 마리분의 생체 원료를 직접 채취해 휴대용 배양 도구에 넣고 첫 민트색 개체를 배양한다.
- 조수마다 능력치와 특화된 연구 계통이 다르다.
- 첫 동료인 조수의 능력치는 무작위로 정한다. 플레이어는 게임 시작 전에 주사위를 횟수 제한 없이 다시 굴려 원하는 능력치 결과를 선택할 수 있다.
- 전문 계통은 연구 속도에서 이점을 얻지만 다른 계통도 연구할 수 있다. 선택하지 않은 조수 때문에 계통 전체를 연구할 수 없게 하지 않는다.
- 조수의 전문성은 평상시 연구 속도, 활동 보너스는 실제 운영·전투 성과에 따른 연구 진척을 담당한다. [연구 규칙](../systems/research.md)을 따른다.
- 연구 활동과 성과를 맵에서의 행동·짧은 보고로 표현하여 연구소에서 일하는 동료로 느끼게 한다.
- 별도의 단서 조사·연구 후보 발견 시퀀스를 연구 진행의 필수 절차로 두지 않는다.

### 건설 개체의 비상 배양

- 주인공과 조수가 살아 있고 건설 가능한 생명체가 한 마리도 없으면, 조수를 선택해 비상 배양을 맡길 수 있다. 조수가 휴대용 배양 도구로 수집·운반·건설이 가능한 기본 민트색 개체 한 마리를 배양한다. 배양시설과 창고 재고가 없어도 시작할 수 있다.
- 휴대용 배양에는 조수가 직접 시간을 써야 하며 그동안 연구를 진행할 수 없다. 가동 가능한 배양시설에서는 재료 공급 후 [자동 배양](../systems/production.md)이 진행되므로 연구를 계속하며 건설 개체를 확보할 수 있다. 평상시에는 시설 배양이 유리하도록 하며, 휴대용 배양의 구체적인 소요 시간은 추후 정한다.

### 일반 배양시설 작업 (후속 개발)

- 2026-11-20 논의한 방향으로, 조수를 선택해 연구 또는 일반 배양시설 작업을 맡길 수 있게 한다. 조수가 맡을 작업에서 건설과 운반은 제외한다.
- 재료가 공급된 시설은 자동으로 배양한다. 조수가 현장에서 작업하는 동안에는 배양 작업 성능에 따라 진행량이 더해지고, 조수가 연구로 돌아가면 시설은 기본 진행을 이어간다. 배양 작업 구현과 조수의 단위 시간당 기여량 조정은 후속 개발에서 진행한다.

## 습격 예고와 대피

- 주인공은 습격 예고가 뜨면 외곽 이동을 멈춘다. 적이 발견되면 자동으로 대피한다.
- 조수는 예고 중에도 연구나 배양을 계속한다. 위협이 가까워지면 작업을 중단하고 자동으로 대피한다.
- 2026-11-20 사용자 결정에 따라 자동 대피한 조수는 현재 위치·복귀 경로·작업 장소의 안전이 확인되면 중단했던 작업으로 스스로 돌아간다. 맵 다른 곳에서 습격이 계속되는 중에도 복귀할 수 있다.
- 플레이어가 조수를 클릭해 **대피**를 선택하면 조수는 즉시 작업을 멈추고 스스로 대피한다. 주변이 먼저 안전해져도 해당 [습격이 종료](../systems/defense.md#습격-종료-기준)될 때까지 지시가 유지된다.

### 대피 후 작업 재개

- 2026-11-20 사용자 결정에 따라 조수가 대피할 때 연구와 휴대용 배양은 진행도를 보존한다. 복귀하면 중단한 연구나 배양을 멈춘 지점부터 이어간다.
- 일반 배양시설을 지원하던 조수가 대피하면 조수의 작업 기여만 멈춘다. 복귀할 때 같은 배양이 진행 중이면 다시 지원한다. 담당 배양시설이 파괴되면 복귀 조건을 충족한 뒤 연구로 전환한다. 시설의 가동 불능과 수리 후 재개는 [시설 배양의 중단과 재개](../systems/production.md#시설-배양의-중단과-재개)를 따른다.

## 주인공의 게임오버와 조수의 회복

- 주인공의 체력이 0이 되는 순간 게임오버다. 조수는 체력이 0이 되면 쓰러진 채 생존하며, 회복할 때까지 연구와 배양 작업을 멈춘다.
- 전투가 끝나면 구조 가능한 생명체가 쓰러진 조수를 회복시설로 옮긴다. 구조할 생명체나 회복시설 중 하나라도 없으면 주인공이 직접 돌본다. 이 경우 시설이나 비축 자원 없이도 조수가 회복하며, 시설에서보다 시간이 오래 걸린다.

## 표현 제안

- 마스코트의 상황 반응과 조수의 연구 보고로 같은 사건에 서로 다른 역할을 부여한다.
- 조수가 표본을 다루거나 연구 시설을 이용하는 모습, 보너스 발생 시 짧은 성과 보고를 검토한다. 구체적인 행동·애니메이션 목록은 미확정이다.

- 근거: 사용자가 기존 분위기를 유지하고, 지하 연구실 대신 수림 평지에서 시작하는 새 기획에 맞춰 아트 디렉션을 이어가도록 지정함.

- 시설 근거: 같은 날 사용자가 초반은 투박한 실험 장비, 후반으로 갈수록 매끈하고 정돈된 첨단 연구 장비로 표현하도록 지정함. 프로토타입은 초반부만 다루므로 투박한 장비만 준비하도록 범위를 한정함.

- 크기 근거: 같은 날 사용자가 슬라임은 사람보다 작고 아담하게, 생명체마다 크기를 다르게 하며 거대한 생명체는 1×1을 넘을 수 있도록 지정함.
- 선명도 근거: 같은 날 사용자가 배경은 부드럽게 하고 생명체와 장비는 또렷하게 보이도록 지정함.
- 조명 근거: 같은 날 사용자가 부드러운 자연광·은은한 그림자·필요한 부분의 작은 발광을 지정함. 발광 개발 시 최신 Unity 문서를 확인하고 최적화에 최대한 신경 쓰도록 요청함.
- 동작 근거: 같은 날 사용자가 평소에는 잔잔하게 움직이고 작업하거나 반응할 때는 동작을 크게 주며, 슬라임은 말랑하고 귀엽게 움직이도록 지정함.
- 장비 재질 근거: 같은 날 사용자가 초반 장비는 무광 금속에 유리 용기와 고무 호스를 조합하고 조립 흔적이 드러나는 수제 실험 장비 느낌으로 지정함.
- 장비 색감 근거: 같은 날 사용자가 장비 본체는 차분한 색으로 하고 기능을 보여주는 부분에만 선명한 색을 소량 사용하도록 지정함.
- 자연물 근거: 같은 날 사용자가 자연물은 큰 형태 위주로 단순화하고 잔디테일은 절제하도록 지정함.
- UI 근거: 같은 날 사용자가 UI는 정돈된 연구 기록 화면에 수제 장비의 투박함과 블랙코미디를 조금 섞는 방향으로 지정함.
- 픽셀 표현 근거: 같은 날 사용자가 인게임은 픽셀 아트로 통일하고 UI 글자는 가독성을 우선하도록 지정함.
- 샘플 순서 근거: 같은 날 사용자가 수림 평지에 작은 연구소가 막 자리 잡은 장면부터 확인하고 첫 배양·첫 건설 장면으로 이어가도록 지정함.
- 샘플 검토 근거: 같은 날 사용자가 실제 플레이 크기에서 UI 포함·제외 화면을 비교하고, 정지 화면 다음에 대기·작업 동작을 확인하며 픽셀 해상도와 크기 비율은 샘플 비교 후 정하도록 지정함.

## 확정한 방향

- **Doom-Inc / 재앙 연구소**는 **귀엽고 기괴한 블랙코미디** 분위기를 유지한다.
- 시작 배경은 [수림 평지의 중앙 터](../systems/maps.md#시작-맵의-자원과-첫-증설)다. 기존 지하 연구실을 새 게임의 시작 배경으로 사용하지 않는다.
- [첫 시작](early-game.md#본편-기획의-시작-구성)은 시설 없는 터의 주인공과 조수, 조수의 휴대용 도구를 통한 첫 민트색 개체 배양이다. 완성된 연구실에서 시작하는 그림으로 바꾸지 않는다.
- 배양한 생명체의 채취·운반·건설을 거쳐 연구소가 확장되는 기존 흐름을 표현한다. 분위기 변경을 이유로 새로운 시설·자원·행동을 추가하지 않는다.
- [UI 기본 배치 검토](interface.md#첫-프로토타입의-pc-화면)는 완료했다. 와이어프레임의 색과 선화는 최종 아트 기준이 아니며, 글꼴·팔레트·정식 아이콘·효과는 [UI 후속 작업](interface.md#ui-후속-작업)과 연결한다.

## 애니메이션의 리듬과 강약

2026-11-26 확정.

- **평소에는 잔잔하게 움직인다.**
- **작업하거나 반응할 때는 동작을 크게 준다.** 평소 동작과 강약을 구분해 행동을 알아보기 쉽게 표현한다.
- **슬라임은 말랑하고 귀엽게 움직인다.** 슬라임의 귀여움을 우선하는 표현 기준을 함께 따른다.

종별 대기·이동·작업·반응 동작의 세부 형태, 변형 정도, 속도·프레임 수·재생 방식은 개별 아트를 구체화할 때 정한다. 동작을 크게 표현한다는 합의로 실제 작업 시간·이동 속도·판정 범위를 변경하지 않는다. 장비의 구체적인 작동 동작은 아직 미정이다.

## 배경과 생명체의 색감

2026-11-26 확정. **배경은 차분한 자연색**, **생명체는 맑고 선명하게 보이는 색감**을 사용한다. 수림 평지의 풀·나무·흙 위에서 생명체를 쉽게 찾아 움직임을 읽을 수 있도록 두 대상의 색감 관계를 잡는다. 슬라임에도 이 색감 방향과 귀여움을 우선하는 표현 기준을 함께 적용한다.

실제 팔레트·개별 색상값·명도와 채도 차이·질감 밀도는 대표 장면에서 비교해 정한다. 특히 풀밭과 민트색 개체처럼 색 계열이 비슷한 조합에서도 구별되는지 확인한다.

장비 본체와 기능 부위의 색감 관계는 아래 [장비의 색과 강조 범위](#장비의-색과-강조-범위)를 따른다. 개별 색상과 UI·경고의 색 기준은 아직 미정이다.

## 자연물의 형태와 디테일

2026-11-26 확정. **자연물은 큰 형태 위주로 단순화하고 잔디테일은 절제한다.** 풀·나무·바위는 차분한 자연색과 부드러운 배경 표현을 함께 따른다.

대상별 실루엣·질감 밀도·변형 수는 실제 표시 크기의 대표 장면에서 비교해 정한다. 형태의 단순화가 자연물의 종류·배치 밀도·점유 크기나 채취 규칙을 바꾸지는 않는다.

## 배경과 대상의 선명도

2026-11-26 확정. **배경은 부드럽게, 생명체와 장비는 또렷하게 보이도록 표현한다.** 차분한 자연색의 수림 평지 위에서 생명체의 윤곽·움직임과 장비의 형태를 쉽게 구분할 수 있도록 외곽선·명암·디테일의 강약을 맞춘다.

이 합의는 대상 간 선명도 관계를 정한 것이다. 외곽선의 정확한 두께·색, 명암 단계 수, 질감 밀도와 슬라임의 하이라이트 방식은 대표 장면에서 비교해 정한다. 배경의 부드러움을 일괄적인 흐림 효과 적용으로 해석하지 않는다.

## 조명과 그림자·발광

2026-11-26 확정.

- **조명은 부드러운 자연광**으로 표현한다.
- **그림자는 은은하게** 표현한다.
- **발광은 필요한 부분에만 작게** 사용한다.

구체 광원 방향·밝기·그림자 길이·발광 색과 강도는 대표 장면에서 비교해 정한다. 시간대 변화·날씨 시스템은 이번 합의에 포함하지 않는다. 발광 개발 시 최신 Unity 공식 문서 확인과 최적화를 요구하며, 실행 기준은 [발광 표현과 최적화 지침](../../agents/implementation.md#발광-표현과-최적화)을 따른다.

## 시설의 발전과 프로토타입 범위

2026-11-26 확정. 본편의 시설은 **초반의 투박한 실험 장비에서 후반의 매끈하고 정돈된 첨단 연구 장비로** 발전하는 인상을 준다.

**현재 프로토타입은 초반부만 다루므로 투박한 실험 장비 쪽만 준비한다.** 후반 첨단 장비의 시안·에셋·단계별 변형은 현재 프로토타입의 제작 범위와 완료 조건에 포함하지 않는다. 본편 후반부를 구체화할 때 이어간다.

이 방향은 장비의 시각적 발전을 뜻한다. 기존 시설의 자동 외형 변경·업그레이드·교체 기능이나 해금 시점을 새로 확정하는 것은 아니다. 초반 시설별 재질의 구체 배치·색·실루엣·작동 부위는 아래 공통 방향과 기존 기능, 제작할 장면에 맞춰 정한다.

### 초반 장비의 재질과 조립 인상

2026-11-26 확정. **무광 금속에 유리 용기와 고무 호스를 조합하고, 조립 흔적이 드러나는 수제 실험 장비 느낌**으로 표현한다.

장비별 재질 비중·연결부의 형태·사용감과 손상 정도는 아직 미정이다. 색감은 아래 기준을 따른다. 이 방향은 외형 기준이며 제작 재료나 건설 비용을 새로 정하지 않는다.

### 장비의 색과 강조 범위

2026-11-26 확정. **장비 본체는 차분한 색으로 하고, 기능을 보여주는 부분에만 선명한 색을 소량 사용한다.**

구체 색상·색상값·강조 부위와 면적은 개별 장비와 대표 장면에서 비교해 정한다. 앞서 제안한 회색·회청색 본체나 짙은 회색 호스를 공통 확정색으로 취급하지 않는다. 선명한 색의 사용과 발광 여부는 구분하며, 발광은 [조명과 그림자·발광](#lighting-and-glow) 기준을 따른다.

## 시점 기준

2026-11-26 사용자 지정에 따라 **현재 인게임 시점은 림월드와 같은 시점을 기준으로 잡는다.** 참고 범위는 화면을 바라보는 시점이며, 림월드의 캐릭터 화풍·시설 디자인·상대 크기까지 함께 채택한 것으로 해석하지 않는다.

구체적인 카메라 수치, 시설의 윗면·앞면이 보이는 정도와 높이 표현은 대표 장면을 비교하며 맞춘다. 사람·슬라임·초반 시설을 같은 화면에 놓았을 때의 세부 비율은 아래 크기 방향에 맞춰 비교한다. 그림에서 보이는 크기와 [맵의 점유·중심 배치 규칙](../systems/maps.md#시작-맵의-자원과-첫-증설)은 구분한다.

## 생명체의 상대 크기

2026-11-26 확정.

- **슬라임은 사람보다 작고 아담한 크기**로 표현한다. 귀여움을 우선하는 외형·움직임 기준을 함께 따른다.
- **생명체마다 크기를 다르게 한다.** 모든 생명체를 사람이나 슬라임과 같은 크기로 통일하지 않는다.
- **거대한 생명체는 1×1을 넘는 크기일 수 있다.** 생명체 전체의 크기를 한 칸 안으로 제한하지 않는다.

정확한 크기 비율·종별 크기·거대한 생명체의 도입 시점은 미정이다. 이 방향만으로 거대한 생명체를 현재 프로토타입의 제작 범위에 추가하지 않는다.

실제 점유 칸·충돌·통로와 문 통과·이동 및 시설 접근 규칙은 해당 생명체의 기획에서 정한다. 1×1 초과를 그림만 커지는 방식이나 반드시 특정 크기의 다중 칸을 점유하는 방식 중 하나로 임의 확정하지 않는다. 기존 자연물·시설의 중심 배치 기준은 유지한다.

## UI의 시각 스타일

2026-11-26 확정. **UI는 정돈된 연구 기록 화면을 바탕으로 수제 장비의 투박함과 블랙코미디를 조금 섞는다.**

패널·버튼·아이콘의 구체 형태, 글꼴·팔레트·장식과 상태별 효과는 이 인상에 맞춰 시안에서 비교한다. 앞서 예시로 제안한 도장·주의 표식 등을 필수 장식으로 확정하지 않는다. [기본 배치 검토](interface.md#첫-프로토타입의-pc-화면)는 완료 상태를 유지하며, 세부 제작과 가독성 검증은 [UI 후속 작업](interface.md#ui-후속-작업)으로 이어간다.

## 픽셀 표현의 적용 범위

2026-11-26 확정. **인게임은 픽셀 아트로 통일하고, UI 글자는 가독성을 우선한다.** 생명체·장비·자연물의 인게임 아트는 이 표현 기준을 함께 따른다.

UI의 구체 글꼴과 패널·아이콘의 픽셀 표현 범위, 원본 해상도·픽셀 밀도·표시 배율은 대표 장면에서 비교해 정한다. 글자의 가독성 우선 원칙만으로 특정 글꼴을 채택하거나 픽셀 글꼴을 일괄 배제하지 않는다. 기존 에셋의 재사용과 수정 여부는 별도 검토한다.

## 대표 장면의 비교 기준

2026-11-26 사용자 지정에 따라 **수림 평지에 작은 연구소가 막 자리 잡은 장면 → 첫 배양 → 첫 건설** 순서로 확인한다. 이는 아트 샘플의 검토 순서이며 실제 게임의 진행 순서를 바꾸지 않는다. 생명체의 표현 수위와 배경·생명체의 색감 방향은 위 기준을 따른다. 구체 색상값·형태·애니메이션은 아직 확정하지 않았다.

| 순서 | 장면 | 플레이어가 읽어야 하는 것 | 아트에서 확인할 점 |
| --- | --- | --- | --- |
| 1 | 수림 평지에 작은 연구소가 막 자리 잡은 장면 | 초반 시설·생명체·자연물이 함께 있는 모습 | 사람과 슬라임의 상대 크기, 시설별 실루엣, 배경과 대상의 구별, UI와 장면의 조화 |
| 2 | 첫 배양 | 조수와 휴대용 도구, 주변 원료, 태어난 민트색 개체 | 수풀과 개체의 구별, 도구의 역할, 탄생 후 움직임 |
| 3 | 첫 건설 | 개체가 채취한 자재와 건설 중인 가공대·바닥 | 운반물과 손의 동작, 미완성·완성의 구분, 바닥 접점 |

샘플의 현재 목적은 아트 방향과 실제 표시 크기의 식별성을 비교하는 것이다. 컨셉아트로 발전시키거나 향후 영상의 구도·장면 구성 참고로 활용할 수 있다. 2026-11-26 사용자 지정에 따라 [실제 홍보영상은 인게임 플레이를 촬영해 제작](../direction/overview.md#홍보영상-제작-방향)한다. 샘플 자체의 홍보용 사용 여부는 미정이다. 샘플 제작과 시각 검수도 아직 진행하지 않았다.

### 샘플의 검토 방법

2026-11-26 확정.

1. **실제 플레이 크기에서 UI 포함·제외 화면을 비교한다.** 같은 장면을 기준으로 아트의 식별성과 UI 글자의 가독성을 확인한다.
2. **정지 화면을 먼저 확인한 뒤 대기·작업 동작을 확인한다.** 확정한 평소의 잔잔한 움직임과 작업 때의 큰 동작, 슬라임의 말랑하고 귀여운 움직임을 비교한다.
3. **픽셀 해상도와 크기 비율은 샘플 비교 후 정한다.** 비교 전의 시안 수치를 최종 제작 규격으로 확정하지 않는다.

기본 방향과 검토 방법의 합의까지 정리했다. 샘플 제작·시각 검수 및 이를 통한 제작 규격 확정은 후속 작업으로 남긴다. 사전준비의 다음 논의는 [11. 사운드](../../todo/pre-production.md)로 이어간다.

## 다음에 정할 표현

- 아트 후속 작업에서는 위 검토 방법에 따라 샘플을 제작·비교하고, 결과를 바탕으로 크기 비율·원본 해상도·픽셀 밀도 등을 구체화한다. 제작·검수 완료와 구체 제작값은 아직 미정이다.
- 확정한 크기 방향에 따라 사람·작고 아담한 슬라임·초반 시설을 같은 장면에서 비교해 구체 비율과 식별성을 맞춘다.
- 초반 시설별 재질 배치·실루엣·작동 부위는 확정한 수제 실험 장비 방향에 맞춰 실제 시설 아트에서 구체화한다. 후반 첨단 장비는 본편 후속 범위로 남긴다.
- 배경·생명체·장비의 확정한 색감 방향을 바탕으로 실제 팔레트·명도·채도 차이·질감 밀도를 비교한다. UI·경고의 색과 강조 범위는 추가로 정한다.
- 확정한 표현 수위 안에서 개별 생명체의 신체 구조·동작을 구체화하고, 블랙코미디를 드러낼 상황 표현을 정한다. 슬라임은 귀여움을 우선한다.
- UI 패널·아이콘의 픽셀 표현 범위와 구체 글꼴, 원본 해상도·픽셀 밀도·표시 배율, 림월드를 기준으로 한 시점의 세부 표현, 확정한 선명도 관계에 맞춘 외곽선·명암의 구체 제작값.
- 실제 표시 크기에서 비교할 대표 장면 스타일 시트와 기준 샘플. 문서의 방향 합의와 이미지의 시각 검수는 구분한다.

## 기존 제작 자료와의 관계

[Art 디자인 MAP](../../../../Art/docs/agetns/design/README.md)의 제작 자료를 참고하되, 지하 연구실과 천장 조명을 전제로 한 문장을 수림 평지의 확정 기준으로 자동 적용하지 않는다. 과거 승인본은 당시 기준의 기록으로 보존하고, 새 장면에서의 재사용 여부는 실제 외형을 비교해 결정한다.

이번 분위기·배경 합의는 광원 방향·시간대 변화·날씨 시스템의 채택을 뜻하지 않는다. 세부 표현은 위 논의에서 결정하며 기존 승인 에셋을 자동 수정하지 않는다. 제작 역할·공통 임포트값·Sprite 요청과 검수 절차는 [아트 지침](../../agents/art-assets.md)을 따른다.

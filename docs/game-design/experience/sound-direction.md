# 재앙 연구소의 사운드 디렉션

- 갱신일: 2026-11-26
- 상태: 기본 분위기·슬라임의 소리 방향, 음악·생명체·장비 소리의 역할, 일상 작업·주요 완료 순간과 위험·문제 상황의 알림, 중요 소리 우선 전달과 겹치는 일상 소리 절제 방향 확정. 음량 조절 범위·음소거 시 정보 전달 확정. 작고 간결하며 결과를 구분하는 UI 조작음 방향 확정. 자연을 바탕으로 연구소의 생활감을 더하는 환경음 방향 확정. 작은 연구소 장면의 청취 검수 순서 합의. 실제 음원 제작·선정·적용·청취 검수와 세부 표현은 후속 작업
- 근거: 사용자가 편안하게 연구소를 운영하면서도 가끔 이상하고 우스운 소리가 들리는 방향과, 슬라임의 말랑하고 귀여운 소리를 승인함.
- 역할 근거: 같은 날 사용자가 음악은 편안한 바탕을 만들고 개성은 생명체와 장비 소리로 드러내도록 지정함.
- 완료음 근거: 같은 날 사용자가 일상 작업은 조용하게 하고 탄생이나 건설 완료처럼 눈여겨볼 순간은 짧고 분명하게 알리도록 지정함.
- 경보 근거: 같은 날 사용자가 일반 문제는 차분하게 알리고 긴급한 위험은 확실하게 구분하며 반복 경보는 절제하도록 지정함.
- 동시 재생 근거: 같은 날 사용자가 중요한 소리는 우선 들려주고 겹치는 일상 소리는 줄이도록 지정함.
- 음량·정보 전달 근거: 같은 날 사용자가 전체·음악·효과음·환경음을 각각 조절하고, 음소거 상태에서도 아이콘과 문구로 필요한 정보를 확인하며 긴급 알림은 색 외에도 표식과 문구로 구분하도록 지정함.
- UI 조작음 근거: 같은 날 사용자가 UI 소리는 작고 간결하게 유지하면서 조작 결과는 구분되도록 지정함.
- 환경음 근거: 같은 날 사용자가 자연의 소리를 바탕으로 연구소의 생활감이 조금씩 더해지는 방향으로 지정함.

- 검수 근거: 같은 날 사용자가 작은 연구소 장면을 기준으로 평시 운영 → 완료와 위험 → 반복·음소거 순서로 확인하도록 지정함.

## 기본 분위기와 슬라임

2026-11-26 확정.

- **편안하게 연구소를 운영하면서도 가끔 이상하고 우스운 소리가 들리도록 한다.** [귀엽고 기괴한 블랙코미디의 아트 방향](art-direction.md#확정한-방향)과 함께 적용한다.
- **슬라임은 말랑하고 귀여운 소리로 표현한다.**

구체 음색·음원·재생 빈도·음량과 각 동작의 소리 연결은 아직 미정이다. 이 합의는 기본 인상에 대한 것으로 음악의 장르·악기나 특정 장비 효과음을 확정하지 않는다.

## 음악과 생명체·장비 소리의 역할

2026-11-26 확정.

- **음악은 편안한 바탕을 만든다.**
- **개성은 생명체와 장비 소리로 드러낸다.** 슬라임은 위의 말랑하고 귀여운 소리 방향을 함께 따른다.

구체적인 음악 장르·악기·재생 간격과 생명체·장비의 개별 음색은 아직 미정이다. 수림 평지의 환경음 구성과 각 소리의 음량 관계는 실제 장면과 음원 비교에서 구체화한다.

## 일상 작업과 주요 완료 순간

2026-11-26 확정.

- **일상 작업은 조용하게 표현한다.**
- **탄생이나 건설 완료처럼 눈여겨볼 순간은 짧고 분명하게 알린다.**

실제 음색·길이·음량, 알림 대상의 세부 목록과 동시 완료 시 재생 방식은 아직 미정이다. 슬라임의 탄생 소리에도 말랑하고 귀여운 표현 기준을 함께 적용한다.

## 위험과 문제 상황의 알림

2026-11-26 확정.

- **일반 문제는 차분하게 알린다.**
- **긴급한 위험은 확실하게 구분한다.** 일반 문제와 일상 완료음을 듣는 상황에서도 긴급함을 알아차릴 수 있도록 표현한다.
- **반복 경보는 절제한다.**

긴급도별 대상·음색·리듬·음량, 반복 간격과 다시 알릴 조건은 아직 미정이다. 앞서 제안한 상황 악화 시 재알림이나 화면 표시 유지 방식은 세부 알림 설계에서 정한다.

## 여러 소리가 겹칠 때

2026-11-26 확정. **중요한 소리는 우선 들려주고, 겹치는 일상 소리는 줄인다.**

상황별 세부 우선순위, 줄일 소리의 종류·음량·재생 수·지속 시간과 복귀 방식은 실제 장면에서 비교해 정한다. 음악을 잠깐 낮추거나 같은 작업음의 재생 수를 제한하는 방식은 검토 후보이며 아직 구체 방식으로 확정하지 않았다.

## 음량 조절과 음소거 시 정보 전달

2026-11-26 확정.

- **전체·음악·효과음·환경음의 음량을 각각 조절할 수 있게 한다.**
- **소리를 꺼도 아이콘과 문구로 필요한 정보를 확인할 수 있게 한다.** 주요 완료·문제·위험 안내에 적용한다.
- **긴급 알림은 색뿐 아니라 표식과 문구로도 구분한다.**

설정의 기본값·조절 단위·세부 음원 분류, 아이콘·표식·문구의 구체 내용과 표시 위치·지속 시간은 후속 설계에서 정한다. [UI 후속 작업](interface.md#ui-후속-작업)에 연결해 실제 표시와 조작을 검증한다.

## UI 조작음

2026-11-26 확정. **UI 소리는 작고 간결하게 유지하면서 조작 결과는 구분되도록 한다.**

선택·확정·취소·실행 불가 등 조작별 소리의 연결, 구체 음색·길이·음량과 연속 조작 시 재생 방식은 후속 설계에서 정한다. 소리를 통한 구분과 함께 [음소거 시 정보 전달](#음량-조절과-음소거-시-정보-전달) 기준을 적용한다.

## 수림 평지와 연구소의 환경음

2026-11-26 확정. **자연의 소리를 바탕으로 연구소의 생활감이 조금씩 더해지도록 한다.**

구체적인 자연음·연구소 음원, 음량·밀도·재생 조건은 실제 장면에서 비교해 정한다. 앞서 예시로 든 바람·풀·나뭇잎·기계 진동·기포 소리는 개별 음원으로 확정하지 않는다. 연구소의 생활감이 더해지는 인상만으로 성장 단계별 자동 음향 전환 기능을 확정하지 않는다.

## 대표 장면의 청취 검수

2026-11-26 검수 방법 합의. 아트의 [작은 연구소 장면](art-direction.md#대표-장면의-비교-기준)을 기준으로 다음 순서로 확인한다.

1. **평시 운영** — 음악·환경음·슬라임·장비 소리가 함께 들릴 때 편안한 운영 분위기와 각 소리의 개성을 확인한다.
2. **완료와 위험** — 탄생·건설 완료·일반 문제·긴급 위험의 알림을 구분할 수 있는지, 소리가 겹쳐도 중요한 정보가 전달되는지 확인한다.
3. **반복·음소거** — 일상 소리와 경보의 반복 피로를 확인하고, 음소거 상태에서도 아이콘·표식·문구로 필요한 정보와 긴급도를 구분할 수 있는지 확인한다.

이 순서는 검수 계획이다. 실제 음원을 준비하거나 장면에 적용해 청취 검수를 마친 상태는 아니다.

## 기존 제작 범위와의 연결

[이미 정한 사운드 제작 범위](../../agents/pre-production/direction/scope.md#사운드-제작-범위)를 따른다. BGM은 직접 제작하고, 공통 효과음은 보유한 Universal Sound FX를 우선 활용하며, 게임 고유의 효과음은 필요에 따라 직접 제작하거나 기존 음원을 편집한다. 환경음의 구체 조달 방식과 개별 음원의 선정·이용 조건 확인은 후속 작업으로 남긴다.

## 다음에 정할 소리

- 기존 제작 범위 안에서 대표 음원을 준비하고, [합의한 순서](#대표-장면의-청취-검수)로 작은 연구소 장면에서 비교·검수한다.
- 기존 게임 상황별 효과음과 UI 조작음의 구체 표현 및 시작·종료 조건.
- 생명체별 동작과 장비별 작동음을 구별할 음색, 슬라임의 말랑하고 귀여운 소리의 구체 표현.
- 확정한 동시 재생 방향 안에서 상황별 세부 우선순위·반복 간격·음량·재생 수를 정하고 반복 피로를 검수한다.
- 환경음의 조달 방식, 기존 제작 범위에 맞춘 개별 음원 선정·이용 조건 확인, 실제 장면에서의 청취 검수.

## 준비 결과와 후속 작업

[사운드 준비 지침](../../agents/pre-production/experience/sound.md)에 따라 상황별 사운드 표와 대표 음원 조달 목록을 준비한다. 현재는 기본 방향·소리의 역할과 일상 작업·주요 완료 순간의 강조 및 위험·문제 상황의 알림·동시 재생·음량 조절·음소거 시 정보 전달·UI 조작음·환경음 방향과 대표 장면의 청취 검수 순서를 합의했으며 음원 제작·선정·적용·청취 검수는 진행하지 않았다. 진행 요약은 [사전준비 점검표](../../todo/pre-production.md)에서 관리한다.

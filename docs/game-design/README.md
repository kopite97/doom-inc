# 게임 기획 MAP

생명체를 배양하고 연구소를 운영하는 **콜로니 시뮬레이션**이다. 자율 행동·연구 특화·완전 자동 방어 전투를 중심으로 기획하며, 적대적 외부 세계와 향후 침공을 구상하고 PC 전환을 고려한다.

현재 문서는 논의를 이어가며 작성하는 **임시 작업 초안**이며, 기획 완료 후 전체 기획안을 다시 정리할 예정이다.

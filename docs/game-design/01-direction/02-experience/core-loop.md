## 목표와 기본 사이클

세계 멸망 게이지를 채우는 것이 한 판의 장기 목표다. 전체 게임은 여러 세계를 파괴하는 방향이지만 프로토타입은 1개 세계로 검증한다.

**시설 배치 → 자원 생산·운반 → 생명체 배양 → 보조형의 운영 지원·침공형 방출 → 전과와 멸망 진행 확인 → 병목 개선·생산 확대 → 반복.**

이 순서는 기본 흐름이다. 각 단계를 반드시 순서대로만 실행해야 하는 제약을 뜻하지 않는다. 현재 시작 구성과 획득·저장 건설부터 가공·배양까지의 진입은 [최초 제공 범위](../../04-delivery/02-release/scope.md)가 담당한다. 생산 회차·개체 출현은 [생산시설](../../02-systems/01-production/facilities.md), 배정·자동 작업은 [보조형 모델](../../02-systems/05-creatures/support-models.md)을 따른다.

<a id="release"></a>

## 침공형 방출 (D-061)

플레이어가 방출 버튼을 누르면 **그때 연구소에서 대기 중인 침공형 전원**을 한꺼번에 밖으로 보낸다. 배양 완료 개체는 방출 전까지 연구소에서 대기하며, 방출 시점은 플레이어가 선택한다.

<a id="reports"></a>

## 지속적인 전과 보고 (D-062)

방출한 침공형의 활동을 짧은 텍스트 보고로 지속적으로 확인한다. 초반에는 하는 일을 상세히 보고하고, 후반에는 큰 공적을 중심으로 보여준다. 보고의 상세 수준과 대상 사건이 진행에 따라 달라진다.

보고 주기·단계 전환 기준·공적 구분·문구는 개발하면서 정한다. 별도 개체 레벨·경험치 시스템을 추가한 결정은 아니다.

<a id="destruction-score"></a>

## 보고와 독립적인 성과 누적 (D-063)

멸망 게이지는 **실제 활동 성과에 따라 자동 누적**된다. 보고 표시·생략·열람 여부는 성과 반영 조건이 아니다. 후반에 작은 활동의 보고가 생략돼도 해당 성과는 계속 반영한다.

성과의 산정·누적 수치와 계산식은 개발에서 정한다. 방출 개체 수에 단순 비례하는 공식을 확정한 것은 아니다.

<a id="external-lifetime"></a>

## 외부 활동 기간과 상태 (D-066·D-077)

- 방출한 침공형은 세계가 멸망할 때까지 계속 활동하며 성과를 쌓는다.
- 게임이 꺼진 동안에는 외부 활동과 성과 누적도 진행하지 않는다. 저장·이어하기는 [플레이 환경](../../04-delivery/01-platform/environment.md)을 따른다.
- 방출한 개체는 연구소 Map에서 제외되지만 개체 정보는 유지한 채 외부 활동 상태로 전환한다. 구조는 [Thing과 정의 데이터](../../05-development/01-architecture/thing-model.md)를 따른다.
- 귀환·수명·전투 손실은 후속 개발이며 프로토타입에 포함하지 않는다.

<a id="run-end"></a>

## 멸망 연출·결과·다시 시작 (D-064)

1. 게이지가 가득 차면 연구소와 외부 활동의 진행을 멈춘다.
2. 간단한 세계 멸망 연출을 보여준다.
3. 연출 후 결과 화면으로 한 판을 마무리한다.
4. ‘다시 시작’을 선택하면 현재 확정한 초기 상태로 새로 시작하고 저장도 초기 상태로 바꾼다.

진행을 정지해도 멸망 연출과 화면 전환은 진행한다. 전환 책임은 [GameFlow와 시스템 책임](../../05-development/01-architecture/game-flow.md), 초기 구성은 [최초 제공 범위](../../04-delivery/02-release/scope.md)를 따른다.

## 개발 중 결정과 후속 개발

| 구분 | 범위 |
| --- | --- |
| 개발 중 결정 | 활동 성과 수치·계산식, 보고 주기·전환 기준·문구, 멸망 연출의 표현·길이, 결과 화면 세부 구성 |
| 후속 개발 | 여러 세계 진행·개체 승계·환생·영구 보너스, 침공형 귀환·수명·전투 손실 |

위 세부값을 모두 사전 승인받아야 개발을 시작할 수 있는 것은 아니다([D-059](../../00-management/02-decisions/record.md#d-059)). 전체 방향은 [게임 콘셉트](../01-identity/concept.md), 실제 프로토타입 완료 판정은 [최초 제공 범위](../../04-delivery/02-release/scope.md)에서 관리한다.

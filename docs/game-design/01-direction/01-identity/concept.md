## 전체 콘셉트

귀엽고 기괴한 생명체를 배양하는 레트로 비밀 연구소를 운영하고, 생명체를 밖으로 보내 짧은 텍스트 전과 보고를 확인하며 여러 콘셉트의 세계를 차례로 파괴하는 모바일 방치형·시뮬레이션 게임이다.

플레이어는 세상을 파괴하는 쪽의 연구소 운영자다. 연구소 안에서는 생산·운반·배치의 효율을 개선하고, 밖에서 거두는 성과는 세계 멸망 게이지로 확인한다. 외부 활동은 전투 시뮬레이션 대신 텍스트 전과로 표현한다. 연구소 내부의 생명체 이동·작업·운반 시뮬레이션은 유지한다.

## 표현과 운영 방향

| 항목 | 현재 방향 | 근거 |
| --- | --- | --- |
| 분위기 | 귀엽고 기괴한 블랙코미디와 레트로 비밀 연구소 | S1-B-02 |
| 핵심 장르 | 방치형과 연구소 운영 시뮬레이션의 결합 | S1-B-03·04 |
| 생명체 역할 | 침공형은 밖에서 성과를 쌓고 보조형은 연구소 운영을 돕는다. | S1-B-01·04 |
| 시각 표현 | 2D 도트(픽셀)와 탑다운 시점 | S1-B-05·06 |
| 연구소 조작 | 플레이어가 시설을 직접 배치하며 플레이 화면에서 줌인·아웃할 수 있다. | S1-B-04·05 |
| 전체 확장 방향 | 정해진 시설을 하나씩 해금하며 연구소를 확장하는 방향이다. 구체적인 해금 조건은 정하지 않았다. | S1-B-05 |

줌과 화면 조작의 현행 범위는 [화면과 조작](../../03-player-experience/03-interface/controls.md), 시설 배치 규칙은 [시설 배치](../../02-systems/03-space/placement.md)를 따른다. ‘방치형’이라는 장르 표현으로 종료 중 진행을 추가하지 않는다. 프로토타입은 게임이 꺼진 동안 진행하지 않는다([D-069](../../00-management/02-decisions/record.md#d-069)).

<a id="prototype-scope"></a>

## 프로토타입과 후속 개발의 구분

- 전체 게임은 다양한 콘셉트의 세계를 차례로 파괴한다. 판타지·SF는 가능한 예시이며 확정된 세계 목록은 아니다.
- 프로토타입은 **1개 세계**에서 게임 사이클을 검증한다. 여러 세계 진행·환생·영구 보너스는 후속 개발이다.
- 현재 콘텐츠·시작 구성·생산 진입은 [최초 제공 범위](../../04-delivery/02-release/scope.md)를 따른다. 전체 해금 방향을 근거로 별도 해금 체계나 강제 배양 순서를 프로토타입에 추가하지 않는다.
- 세계 멸망 시 연출·결과·다시 시작은 [목표와 반복 흐름](../02-experience/core-loop.md#run-end)을 따른다.

## 아직 정하지 않은 범위

정식 게임명은 확인되지 않았다. 후속 세계 목록·세계별 데이터와 에셋·전환·해금 조건의 상세는 후속 개발에서 정한다. 과거 예시의 생명체 수·자원 수·수치·수익 모델은 승인된 현재 범위를 늘리는 근거가 아니다.

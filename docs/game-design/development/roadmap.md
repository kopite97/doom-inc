- 근거: 개발 순서 분리 논의와 2026-11-17 추가 성장 요소 채택 및 외부 침공 상세 기획 유보. 추가 주제의 단계 배치는 재검토 예정.

## 진행 방향

콜로니 시뮬레이션의 자율 행동과 관찰 화면을 먼저 연결한다. 기초 커맨더가 있는 작은 연구소에서 플레이어 제어 없는 자동 습격 전투를 경험한 뒤 성장·전투의 깊이를 확장한다.
완료 기준은 앞으로 확인할 목표다. 이전 프로토타입의 완료 기록을 새 단계의 완료로 가져오지 않는다.

조수·[연구](../systems/research.md)·[사건](../systems/events.md)·[외부 세력](../systems/external-world.md)·[건설](../systems/construction.md)이 기획에 추가됐다. 아래는 기존 초기 순서이며 새 주제의 상세 단계·선행 관계를 모두 반영한 실행 계획은 아니다. 외부 침공의 단계·범위는 상세 기획 후 정한다.

| 단계 | 목표와 범위 | 선행 조건 | 완료 시 확인할 경험 | 이번 단계 밖 |
| --- | --- | --- | --- | --- |
| 1. 생명체와 자율 행동 | 가능한 행동·개체 코스트·기본 작업 선택과 생산·운반 흐름 | [생명체](../systems/creatures.md)·[작업](../systems/work.md)의 해당 규칙 결정 | 가능한 일을 자율 수행하고 직접 조정의 효과가 나타남 | 고급 커맨더·전체 전투 |
| 2. PC 관찰·개입 UI | 행동·대기 이유·기본 설정을 확인하는 최소 화면 | 1단계의 행동·작업 설정 규칙. 1단계와 작은 단위로 연계 | 행동을 이해하고 필요한 설정을 바꿀 수 있음 | 전체 UI 아트·모바일 병행 대응 |
| 3. 기초 커맨더 | 기본 배분과 명령 상호작용 | 1~2단계, 기본 배분 기준·적용 범위·수동 설정 관계 결정 | 명령으로 배분이 달라지고 반복 설정이 줄어듦 | 상위 알고리즘 전체 |
| 4. 작은 기지 습격 | 예고·등장·자동 대응·승패·일상 복귀를 좁은 범위로 연결 | 1~3단계, [전투](../systems/defense.md)의 승패·손실·자동 행동 규칙 결정 | 플레이어 전투 명령 없이 진행·결과를 이해하고 정상 작업으로 복귀함 | 수동 전투 제어, 복잡한 부상·엄폐·다수 적 전술 |
| 5. 성장과 운영의 깊이 | 추가 논의에서 채택한 다양한 성장 요소와 상위 커맨더 | 앞선 플레이 평가, [성장 초안](../experience/growth.md)의 확장 논의와 채택안 결정 | 성장 전후 모습·가능한 일·운영 방식이 달라짐 | 기존 외부 목표·세 예시를 전체 성장 구조로 고정하는 것 |
| 6. 전투·콘텐츠·표현 확장 | 선택한 적·능력·전술·연출·밸런스 보강 | 핵심 흐름 확인과 확장 범위 결정 | 확장 콘텐츠가 기존 흐름과 일관되고 조작·판단·결과가 이해됨 | 미채택 콜로니 시스템 |

## 기획 확정과 경험 확인

- 1~2단계는 행동을 관찰하고 운영에 개입하는 작은 흐름으로 함께 확인할 수 있다.
- 해당 단계에 필요한 미정 게임 규칙을 먼저 결정한다. 이후의 성장 요소와 전투 확장 범위를 미리 모두 확정할 필요는 없다.
- 플레이 결과에 따라 경험 확인 순서·범위를 조정하고 이유를 갱신한다.
- 출시 범위·일정·최종 완료 기준은 미정이다. 이 순서만으로 출시 준비 완료를 판정하지 않는다.

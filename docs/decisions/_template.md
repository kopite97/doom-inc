## 문제와 제약

선택이 필요한 이유와 현재 구현 범위를 적는다.

## 결정

선택한 방법과 적용 범위를 적는다. 검토 중 제안과 실제 적용을 구분한다.

## 대안과 선택 이유

실제로 고려한 대안과 선택 이유를 간단히 적는다.

## 영향과 검증

상태 소유·참조·저장 호환성·성능 등 관련 영향과 검증 방법을 적는다.
실제 실행 결과는 해당 PLAN의 검증 기록에 연결한다.
